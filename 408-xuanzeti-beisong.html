第1章 基本概念与时空复杂度

1.1.1算法时空复杂度真题 8 次

知识点

  • 复杂度量级链：O(1) < O(log2 n) < O(n) < O(n log2 n) < O(n²) < O(n³) < O(2^n) < O(n!) < O(n^n)。
  • 主定理：T(n) = aT(n/b) + O(n^d)，比较 log_b a 与 d 定量级；归并排序 T(n) = 2T(n/2) + O(n)，log_2 2 = 1 = d，故为 O(n log n)。
  • 循环变量倍增（如 i *= 2）执行约 log2 n 次；递归须写出递推式再展开求解。
  • 算法 5 特性：有穷性、确定性、可行性、输入 ≥ 0 个、输出 ≥ 1 个。
  • 原地工作指辅助空间 O(1)，不随输入规模 n 增长。

口诀 / 技巧 / 易错点 （源B：第1章 绪论）

  • while 三步：设 t 次 → 写变量通式 → 用边界列等式 → 解出 t 只留量级。
  • 等比求和：首项 a、公比 q（q≠1）、n 项 → a(qⁿ−1)/(q−1)；等差求和：n(a₁+aₙ)/2。
  • 双层 for 先标"外层第几次"：外层变量常是 1、2、4、8 跳变，只看变量本身会数错次数。
  • 近似原则：2^(t+1)→2^t，n/2→n，t+1→t，t²+t→t²，2n−1→n；做完近似再看量级。
  • 看到每次乘 2 / 除 2 → log；看到累加 1+2+…+t → 平方根；看到内层次数成等比 → 总和由末项决定 → 一次方。
  • 空间复杂度只看额外空间：辅助数组、递归栈；输入本身不计。
  • 易错：把双层 for 直接相乘；算出 log₂n−2、n/2、2n−1 时不要慌，选项只给量级；对数底数纠结（log₂n 与 log₃n 同一量级）。
  • 易错：递归只数"层数"忘记乘每次开销；空间复杂度漏掉递归栈（阶乘递归空间是 O(n) 不是 O(1)）。

第2章 线性表

1.2.2线性表的链式存储真题 3 次

知识点

  • 顺序表按位查找 O(1)（随机存取），链表按位查找 O(n)；已知指针时链表插删 O(1)，顺序表插删 O(n)。
  • 顺序表存储密度为 1；单链表 < 1，双向链表更低。
  • 判空（带头结点）：单链表 head->next == NULL；循环单链表 head->next == head；双向链表 head->next == NULL；静态链表 next == -1。
  • 快慢指针找中点、找倒数第 k 个结点、判环；头插法原地逆置 O(n)/O(1)；归并双指针合并有序单链表。

口诀 / 技巧 / 易错点 （源B：第2章 线性表）

  • 顺序表：随机存取快，插删要搬家，空间要连续，长度得先定；链表：插删只改针，找位要走路，空间碎片化，指针占密度。
  • 出现"平均"→ 顺序表插删一律 O(n)；出现"第 i 个"→ 顺序表 O(1)，链表 O(n)；出现"给定指针 p"→ 链表插删 O(1)。
  • 插入"先连后断"：先用 p->next 把新结点接上，最后再改 p->next 指向新结点；"先给新结点找好退路，再动老指针。"
  • 双链表插入四步口诀："后连后、后回指、前指 p、p 指 s"，最后一步永远是改 p->next，必须排最后。
  • 删除三件套："存 q → 跨过 q → free(q)"，一句不能少。
  • 判空速查（带头结点）：单链表 L->next == NULL；循环单链表 L->next == L；循环双链表 L->next == L 且 L->prior == L。
  • 易错：头指针 ≠ 头结点，求表长时头结点不计入；插入顺序写反导致断链；删除时 free 错对象；笼统说"链表插删 O(1)"，正确说法是已知前驱时改指针 O(1)，按位序插删总时间 O(n)。

1.5.1KMP 匹配算法真题 2 次

知识点

  • next[j] 为模式串前 j 个字符中前缀与后缀最长相等长度（0 开始口径：next[0] = -1；失配时 j 回退到 next[j]，主串指针 i 不回退）。
  • KMP 时间复杂度 O(n+m)；比较次数须逐次累加，回退后当前位置要重新比较。
  • next 数组递推（王道 DS 指导 4.2.2 p.116，1 开始口径 next[1] = 0）：next[j] 是使"前缀 = 后缀"的最大 k（1 < k < j），无此 k 时为 1；求 next[j+1] 时若 p_k = p_j 则 next[j+1] = next[j] + 1，否则回退到 next[next[…[k]]] 再比。
  • nextval 优化（王道 DS 指导 4.2.3 p.121，1 开始口径）：从 j = 2 开始，若 p_j = p_{next[j]} 则 nextval[j] = nextval[next[j]]（已求得的值），否则 nextval[j] = next[j]；nextval[1] = next[1] = 0。
  • 位序口径换算（王道 DS 指导 4.2.3 p.121）：串的位序从 1 开始时 next 数组整体加 1，从 0 开始时不加 1；做题先看题干给的位序，再定 next[0] 是 −1（0 开始）还是 1（1 开始）。
  • KMP 主流程（ddy OneNote 数据结构第4章，get_next 与 Index_KMP）：先算 next 数组，再用主串指针 i 与模式串指针 j 同步比较；失配时 i 不动、j 回退到 next[j] 再比；时间复杂度 O(m+n)。

口诀 / 技巧 / 易错点 （源B：第4章 串）

  • "第一个 1、第二个 0"：next[0] = 1、next[1] = 0，先把这两个写死，再从左往右推。
  • "只看前面、不看自己；错开一位、完全相等"：求 next[j] 的铁律。
  • "同字符就继承，不同字符就保留"：nextval 一句话规则；继承时用已更新的 nextval 值。
  • "非 1 主串不动，是 1 主串加一"：判断 i 是否前进只看 next（或 nextval）是否为 1。
  • 滑动距离 = j − next[j]；若问"最长滑动距离"，把所有 j 的 j−nextval[j] 都算出来取最大。
  • 比较次数不要用"滑了几位"去减：回退后当前位置要重新比，逐次累加最稳。
  • 易错：next 与 nextval 混用下标口径；以为失配后主串一定不动；比较次数按"位移"算（2019 题若答 6+3 = 9 就错，正确是 6+4 = 10）。
  • 注意：源B用 1 开始口径（next[0] = 1），真题解析用 0 开始口径（next[0] = -1），换算时注意（两源说法不一致，以真题解析为准）。

第3章 栈、队列和数组

1.3.1栈真题 11 次

知识点

  • 卡特兰数：n 个不同元素依次进栈，合法出栈序列总数为 (2n)! / ((n+1)! n!)。
  • 非法出栈序列判定：对任一元素 x，在 x 之后出栈且原序列中排在 x 之前的元素须降序排列。
  • 中缀转后缀：操作数直接输出；左括号压栈；右括号弹至左括号并丢弃；运算符须高于栈顶才压栈，否则一直弹（相等也弹，左结合）。
  • 后缀求值：先弹出的操作数为右操作数（减法、除法别写反）。

口诀 / 技巧 / 易错点 （源B：第3章 栈、队列和数组）

  • 栈："后进先出，一端进出"；队列："先进先出，一端进另一端出"。
  • 顺序栈判空判满：top = -1 起 → 空 -1、满 MaxSize-1；top = 0 起 → 空 0、满 MaxSize；先移再存指向栈顶，先存再移指向栈顶之上。
  • 中缀转后缀口诀："数直接出，左括号进，右括号弹到左括号，运算符外面大才进、否则一直弹"；相等也弹（左结合）。
  • 后缀求值口诀："先弹的当右边"（减法、除法别写反）。
  • 卡特兰数速算：n = 3 → 5，n = 4 → 14，n = 5 → 42（记这三个数足够应付选择）。
  • 递归树：结点数 = 时间，高度 = 空间。
  • 易错：后缀求值弹出顺序反了；中缀转后缀遇右括号不入栈，弹出的左括号丢弃（后缀里没有括号）；卡特兰数的前提是入栈顺序固定、元素互异、栈容量不限。

1.3.2队列真题 6 次

知识点

  • 循环队列（front 指队头、rear 指队尾下一个位置）：牺牲一单元法队空 front == rear、队满 (rear+1) % MaxSize == front、长度 (rear-front+MaxSize) % MaxSize。
  • 另两种判满方案：size 计数器（size == 0 空、size == MaxSize 满）；tag 标记（front == rear 且 tag 为 0/1）。
  • 队列先进先出，一端进、另一端出。
  • 双端队列变体（一端只进、另一端又进又出）：画一条横线，左端只进不出、右端又进又出；出队顺序就是从右端依次取走的顺序，从左端后进的元素排在更左。

口诀 / 技巧 / 易错点 （源B：第3章 栈、队列和数组）

  • 循环队列三句：入队动 rear、出队动 front、都要 % M；"空看相等，满看 rear 追上一格就撞 front"。
  • 长度公式：(rear - front + M) % M，M 是容量；两端都开区间时再减 1。
  • 易错：长度公式里的 M 是容量（题目给 0..M-1 共 M 个单元、实际只存 M-1 个，取模仍用 M）。
  • 易错：判满公式与初始化绑定，(rear+1) % M == front 只在"front 指队头、rear 指队尾后一个"时成立，换约定必须重推。
  • 易错：链队出队删到最后一个结点必须 rear = front，否则 rear 悬空；只用 front == rear 判满时，装满一圈与空无法区分，必须靠"牺牲一个单元"。
  • 特殊队列判合法：先想清楚每个元素进的是左端还是右端，再看右端露出的是谁；取走一个后，右端新露出的元素决定了后续序列。

1.4.2特殊矩阵的压缩存储真题 3 次

知识点

  • 对称矩阵 A[n][n] 按行优先存入一维数组 B[k]（下标均从 0 开始）：k = i(i+1)/2 + j（i ≥ j）；上三角元素先转置为下三角再算。
  • 二维数组地址（王道 DS 指导 3.4.2 p.103）：行优先 LOC(a_ij) = LOC(a_00) + [i×(h2+1) + j]×L；列优先 LOC(a_ij) = LOC(a_00) + [j×(h1+1) + i]×L（h1、h2 为行、列下标上界，L 为每个元素占的存储单元数）。
  • 特殊矩阵压缩存储（王道 DS 指导 3.4.3 p.103）：值相同的多个元素只占一个存储空间、零元素不分配空间，目的是节省存储空间；常见对称矩阵、上下三角矩阵、对角矩阵。
  • 对称矩阵按列优先存上三角（王道 DS 指导 3.4.3 p.104，下标从 0 开始）：k = j(j−1)/2 + i − 1（i ≤ j）；下三角元素先转置再算（与行优先存下三角时上三角元素的公式相同）。
  • 三角矩阵（王道 DS 指导 3.4.3 p.104）：下三角矩阵存下三角区＋主对角线＋1 个常量，共 n(n+1)/2 + 1 个存储单元；下三角区元素 k = i(i−1)/2 + j − 1（i ≥ j），上三角区元素 k = n(n+1)/2；上三角矩阵同理，k = (i−1)(2n−i+2)/2 + (j−i)（i ≤ j），下三角区元素 k = n(n+1)/2。
  • 三对角矩阵（王道 DS 指导 3.4.3 p.105）：|i−j| > 1 时 a_ij = 0，非零元集中在主对角线为中心的三条对角线；按行优先存入 B（a_11 存 B[0]），k = 2i + j − 3（A 下标从 1 开始、B 下标从 0 开始）；若 B 下标从 1 开始则 k = 2i + j − 2；反推 i = ⌊(k+1)/3 + 1⌋、j = k − 2i + 3。

1.6.1二叉树的概念与存储真题 6 次

1.6.2二叉树的遍历与线索化真题 10 次

1.7.5拓扑排序与关键路径真题 10 次

知识点

  • 拓扑排序：统计入度、入度为 0 进栈/队列；输出个数不足 V 则必有环；邻接表 O(V+E)。
  • 拓扑序列唯一当且仅当每一步入度为 0 的顶点恰好一个。
  • 关键路径：ve 取 max（正推）、vl 取 min（倒推）；活动最早开始 e 看起点 ve，最迟开始 l 看终点 vl 减权；e = l 的活动为关键活动。
  • 关键路径长度为权值之和最大的路径；缩短任一关键活动未必缩短工期（多条关键路径时须缩短共有活动）。
  • 活动的时间余量 = l − e = vl(终点) − ve(起点) − 边权；余量为 0 的活动是关键活动；求余量最大：正推 ve 取 max、倒推 vl 取 min，再逐活动算余量。

口诀 / 技巧 / 易错点 （源B：第6章 图）

  • 关键路径口诀："正推取最大，倒推取最小；e 看头，l 看尾减权；e = l 是关键"。
  • 关键路径速判：只算 ve，ve(汇) = 长度；从汇点倒推 d = 0 的边即关键路径。
  • 拓扑判环："输出个数不足 V，必有环"。
  • 易错：关键路径正倒推取最值搞反（ve 取 max，vl 取 min）；e 与 l 的取点搞反（e 用起点的 ve，l 用终点的 vl 减权）；关键路径长度 ≠ 边数最多，是权值之和最大；"缩短任一关键活动就能缩短工期"是错的（多条关键路径时只有缩短所有关键路径共有的活动才有效）；"延长任一关键活动一定延长工期"是对的；拓扑序列不唯一 ≠ 拓扑排序不存在。

1.8.5平衡二叉树真题 7 次

知识点

  • AVL 定义：任意结点左右子树高度差 ≤ 1；查找/插入/删除严格 O(log2 n)。
  • 四种旋转：LL/RR 单旋，LR/RL 双旋；只调最小不平衡子树（源B）。
  • LL（右单旋）：在 A 的左孩子的左子树插入，A 的平衡因子由 1 增至 2；把 A 的左孩子 B 向右上旋转代替 A 成根结点，A 向右下旋转成 B 的右子树的根，B 的原右子树作 A 的左子树。
  • RR（左单旋）：在 A 的右孩子的右子树插入，A 的平衡因子由 1 减至 -2；把 A 的右孩子 B 向左上旋转代替 A 成根结点，A 向左下旋转成 B 的左子树的根，B 的原左子树作 A 的右子树。
  • LR（先左后右双旋）：在 A 的左孩子的右子树插入，A 的平衡因子由 1 增至 2；先把 A 的左孩子 B 的右子树的根结点 C 向左上旋转提升到 B 的位置，再把 C 向右上旋转提升到 A 的位置。
  • RL（先右后左双旋）：在 A 的右孩子的左子树插入，A 的平衡因子由 -1 减至 -2；先把 A 的右孩子 B 的左子树的根结点 C 向右上旋转提升到 B 的位置，再把 C 向左上旋转提升到 A 的位置。
  • 删除：先按二叉排序树的方法删结点 w，再从 w 向上回溯找第一个不平衡结点 z（最小不平衡子树）；y 为 z 的高度最高的孩子，x 为 y 的高度最高的孩子；四种位置组合与插入的调整方式相同。与插入不同：删除后如子树高度减 1，可能需要对 z 的祖先结点继续调整，甚至回溯到根。（王道 DS 指导 7.3.2，pp.273–276）
  • 高度 h 的 AVL 最少结点数 N(h) = N(h-1) + N(h-2) + 1：1, 2, 4, 7, 12, 20, 33, 54, 88（源B）。
  • AVL 插入、删除都可能引起旋转调整，删后插回未必复原（2019-4 真题解析）。

口诀 / 技巧 / 易错点 （源B：第7章 查找）

  • AVL 判型：从不平衡点沿插入方向走两条边，LL/RR 单旋，LR/RL 双旋。
  • AVL 快速做法："上找第一个不平，下取前三个，小中大重排，其余按大小挂回"。
  • AVL 删除判型：改"沿插入方向"为"哪边高往哪走"，等高与上层同向。
  • AVL 最少结点：N(h) = N(h-1) + N(h-2) + 1：1, 2, 4, 7, 12, 20, 33, 54, 88（"斐波那契 +1"）。
  • 易错：AVL 删除沿用插入的判型方向——错，删除必须从失衡点往"高度大"的子树走；只调最小不平衡子树，有多个失衡结点时只调最靠下的那个；LR 与 RL 的旋转顺序颠倒（LR 是"先左旋下面、再右旋整体"，RL 反之）；N(h) 边界写错（N(0) = 0、N(1) = 1），最多结点是 2^h-1，不要与最少混。

  • 装填因子 α = 表中记录数 n / 散列表长度 m；散列查找效率取决于散列函数、冲突处理策略、装填因子。

  • 成功 ASL：从散列位置数到元素本身；失败 ASL：对散列函数每个可能值数到第一个空单元（空单元算 1 次），分母为值域大小（源B）。
  • 删除必须逻辑删除（打标记），物理抹空会截断探测链（源B）。

口诀 / 技巧 / 易错点 （源B：第7章 查找）

  • 散列成功 ASL：拿元素算 H(k)，从该位置数到元素本身，几次就几。
  • 散列失败 ASL：对 H 的每个可能值，数到第一个空单元，空单元算 1 次；分母 = 值域大小（除留余数法 = p）。
  • 散列删除：打标记，逻辑删除，绝不抹空。
  • 易错：散列表物理删除——抹空会截断探测链，导致后面的同义词查不到；散列失败 ASL 只对已存元素算——错，要对散列函数的每个可能取值都算一遍；"空单元算不算一次"——408 真题惯例：算（与空位置比较也是一次比较）；拉链法失败分母是散列函数值域大小（如 mod 13 → 13 条链），不是元素个数；装填因子 α = n/m（记录数/表长），不是 m/n，开放定址 α 必须 < 1。

1.8.7B 树与 B+ 树真题 10 次

知识点

  • m 阶 B 树：所有叶子在同一层；除根外非叶结点孩子数 ≥ ⌈m/2⌉，关键字数 ⌈m/2⌉-1 ~ m-1；根最少 1 个关键字（特例）。
  • B 树插入看上限：满 m 个就裂，中间 ⌈m/2⌉ 上位，根裂树高 +1；删除看下限：先直接删，不行借（父子换位），再不行合并（带父关键字）（源B）。
  • 分裂（插入时）：插入位置一定是最低层的某个非叶结点；插入后若结点关键字个数大于 m-1，必须分裂。取一个新结点，在插入后的原结点从中间位置 ⌈m/2⌉ 把关键字分为两部分，左部分留在原结点，右部分放新结点，中间位置 ⌈m/2⌉ 的结点插入原结点的父结点；若父结点也超限则继续分裂，直至传到根结点，树高增 1。
  • 删除与合并：删除后要使结点关键字个数 ≥ ⌈m/2⌉-1。被删关键字不在终端结点，用其前驱（或后继）替代，转化为终端结点删除。终端结点删除分三种情况：① 直接删除（删后结点关键字个数仍 ≥ ⌈m/2⌉）；② 兄弟够借（被删结点删前关键字个数 = ⌈m/2⌉-1，且相邻兄弟关键字个数 ≥ ⌈m/2⌉，调整该结点、兄弟结点及其双亲结点，即父子换位法）；③ 兄弟不够借（合并——将该结点、兄弟结点及父结点中分隔两者的关键字合并成一个结点，若父结点因此关键字数不足则递归处理）。
  • 非叶结点结构：[n, P0, K1, P1, K2, P2, …, Kn, Pn]，关键字递增，指针 Pi-1 所指子树关键字均小于 Ki，Pi 所指子树均大于 Ki，关键字个数 n 满足 ⌈m/2⌉-1 ≤ n ≤ m-1。
  • m 阶 B 树高度：含 n 个关键字、阶为 m 的 B 树，h ≥ log_m(n+1)，h ≤ log_⌈m/2⌉((n+1)/2)+1。例：3 阶 B 树 8 个关键字，2 ≤ h ≤ 3.17。（王道 DS 指导 7.4.1，pp.296–298）
  • B+ 树：非叶结点仅存索引，所有数据在叶子链表中，叶结点按关键字从小到大顺序链接，支持顺序查找与范围查询；n 个关键字对应 n 个分支，无 +1。
  • B 树磁盘读写代价低、查询效率稳定，适用于文件索引与数据库索引。

口诀 / 技巧 / 易错点 （源B：第7章 查找）

  • B 树上下界：关键字 ⌈m/2⌉-1 ~ m-1，分支 ⌈m/2⌉ ~ m，根是特例 1 个起。
  • B 树插入：看上限，满 m 个就裂，中间 ⌈m/2⌉ 上位，根裂树高 +1。
  • B 树删除：看下限，先"直接删"，不行"借（父子换位）"，再不行"合并（带父关键字）"。
  • B 树高度：最小：大家都塞满 log_m(n+1)；最大：大家都取最少 log_{⌈m/2⌉}((n+1)/2)+1。
  • 易错：把"阶"当成关键字数——m 阶是分支数上限；B 树根结点套用下限公式——根最少 1 个关键字（2 个分支），这是特例；B 树删除乱合并——只有兄弟也不够借时才合并，合并一定要把父结点中那个分隔关键字一起并进来；B 树插入分裂位置随意取——规范是 ⌈m/2⌉，m 为偶数时中间偏左/偏右都可，但整题必须一致；B+ 树按 B 树数分支——B+ 树 n 关键字对应 n 个分支，没有"+1"。

  • 直接插入：平均 O(n²)，最好 O(n)，最坏 O(n²)，空间 O(1)，稳定；基本有序时效率极高。

1.9.6堆排序真题 5 次

知识点

  • 堆排序：平均/最好/最坏均为 O(n log2 n)，空间 O(1)，不稳定；建堆严格 O(n)，堆顶下沉 O(log n)；适合求海量数据 Top-K。

口诀 / 技巧 / 易错点 （源B：第8章 排序）

1.9.7归并排序真题 4 次

知识点

  • 二路归并：平均/最好/最坏均为 O(n log2 n)，空间 O(n)，稳定；归并的含义是将两个或两个以上有序表合并为一个新有序表。

  • 败者树：非叶结点记败者段号，顶层 ls[0] 记冠军；重赛沿单一路径向上比对，选全局最小只需 ⌈log2 k⌉ 次比较。
  • 最佳归并树：以各段块数为权构造 k 叉哈夫曼树，总 I/O = 2 × WPL；虚段补齐：(n0-1) mod (k-1) ≠ 0 时补 (k-1) - [(n0-1) mod (k-1)] 个权 0 虚段。
  • 置换-选择排序：动态冻结小于上一输出值的元素，生成平均长度 2w 的超长初始归并段。

口诀 / 技巧 / 易错点 （源B：第8章 排序）

2.1.1计算机层级结构真题 4 次

知识点

  • 冯·诺依曼机五大部件：运算器、控制器、存储器、输入设备、输出设备；指令和数据以同等地位存于存储器中，形式上无差别，按地址寻访。
  • 指令和数据均采用二进制表示；指令由操作码和地址码组成；传统冯·诺依曼架构以运算器为中心，现代计算机以存储器/Cache 为中心。
  • 硬件能直接执行的只有机器语言（二进制编码）；汇编语言是机器语言的符号表示，须经汇编后才能执行。
  • 翻译程序：编译程序一次全部翻译成目标程序（源程序不变无须重编译）；解释程序翻译一句执行一句，不生成目标程序；汇编程序把汇编语言源程序翻译为机器语言程序。
  • 采用二进制的原因：运算规则简单；只需高低两种电平，物理器件易制造；与逻辑量"真/假"吻合，便于用逻辑门电路实现运算。

2.2.1定点数的表示与运算真题 8 次

知识点

  • 原码范围 ±(2^(n-1)-1)，+0 ≠ -0（双重 0）；反码范围同原码，也有双重 0；补码范围 -2^(n-1) ~ 2^(n-1)-1，0 唯一，负数比正数多一个。

  • 溢出判据：同号相加得异号即溢出；进位法 V = Cn ⊕ Cn-1；双符号位 01 正溢、10 负溢。
  • 逻辑移位左移右移空位都补 0；算术移位符号位不参与移动，右移空位补符号位，左移空位补 0。
  • 标志位：CF 服务于无符号数（进位/借位），OF 服务于有符号数（溢出）；进位 ≠ 溢出，最高位有进位丢弃不代表溢出。
  • n 位补码最小值 100…0 = -2^(n-1)，最大值 011…1 = 2^(n-1)-1；全 1 补码 = -1。

  • 判溢出三法：范围法看真值是否越界；符号法同号相加得异号即溢出；进位法 V = Cn ⊕ Cn-1。
  • 算术右移 vs 逻辑右移：左移两者一样（低位补 0），只有右移不同——逻辑右移高位补 0，算术右移高位补符号位。

2.2.2浮点数的表示与运算真题 9 次

知识点

  • IEEE 754 真值公式：X = (-1)^S × (1.M) × 2^(E-Bias)；单精度 32 位：1 位符号、8 位阶码（Bias = 127）、23 位尾数（隐藏最高位 1，有效精度 24 位）。
  • 双精度 64 位：1 位符号、11 位阶码（Bias = 1023）、52 位尾数（有效精度 53 位）。
  • 特殊阶码：阶码全 0 + 尾数全 0 为 ±0；全 0 + 尾数非 0 为非规格化数；全 1 + 尾数全 0 为 ±∞；全 1 + 尾数非 0 为 NaN；规格化数阶码只能取 1~254。
  • 最小规格化正数：数符 0、阶码取 1、尾数全 0，即 1.0×2^-126。
  • 浮点加减步骤：对阶、尾数运算、规格化、舍入、判溢出；对阶是小阶向大阶看齐。
  • 对阶不会引起阶码上溢或下溢；右规和尾数舍入都可能引起阶码上溢；左规时可能引起阶码下溢；尾数溢出时结果不一定溢出。
  • 十进制小数转二进制可能无限循环，无法用精度有限的 IEEE 754 格式精确表示。

第3章 存储器层次结构 (Cache / 主存)

2.3.1主存储器与 CPU 的连接真题 15 次

知识点

  • 芯片数 = 目标总容量 ÷ 单片容量；字扩展改字数（组数管地址），位扩展改字长（每组片数管位数）。
  • 地址范围算个数：末 - 首 + 1（闭区间），如 5FFFH - 4000H + 1 = 2000H = 8KB。
  • MAR 位数取主存地址空间（理论最大寻址范围），不是实际主存容量；如 64MB 地址空间 ⇒ MAR 至少 26 位。
  • DRAM 地址引脚：行列地址线复用，地址引脚数取行、列所需位数的较大者；数据引脚数 = 单元位数。
  • DRAM 用电容存储，工作期间必须定时刷新；刷新按行进行，一行刷新一次，刷新计数器位数 = 行地址位数。
  • SRAM 与 DRAM 都易失，断电都丢数据；Cache 用 SRAM，主存用 DRAM。
  • 多模块低位交叉：模块号 = 地址 % 模块数；相邻 m 次访问落同一模块即可能发生访存冲突；低位交叉流水条件 m = T/r。
  • 容量 = 2^MAR × MDR；按字节编址时地址数 = 字节数。
  • 主存储器（MM）在 CPU 外，存指令和数据，由 RAM 和 ROM 实现；控制存储器（CS）在 CPU 控制器内，存全部微指令，只读不写。

口诀 / 技巧 / 易错点 （源B：04_第3章_3.1-3.3存储器与主存扩展）

  • 芯片数 = 目标总容量 ÷ 单片容量；拆开写就是"组数 × 每组片数"，组数管地址，每组片数管位数。
  • 地址引脚：先求总单元数取 log2 得地址位数，DRAM 再减半；或拆行、列后取较大者。

  • 高位交叉：÷模块容量，商体号、余体内地址；低位交叉：÷模块个数，商体内地址、余体号。
  • SRAM 与 DRAM 都易失，别把 SRAM 当成非易失；DRAM 刷新按行，不按单元、不按列。
  • 存取周期 ≠ 存取时间，Tm = Ta + 复原时间，Tm > Ta，带宽用 Tm 算。
  • 高位交叉不提高带宽，只是扩大容量；同时启动必须地址对齐，否则要拆成多个周期。

知识点

  • 闪存（Flash）是 EEPROM 的进一步发展，可读可写，用 MOS 管浮栅上有无电荷存信息；它仍属 ROM 的一种，写速度比读速度慢不少。
  • 闪存是非易失性存储器，采用随机访问方式；常见 SSD 固态硬盘即由 Flash 芯片组成。
  • 海明码纠一位错：校验位数 k 须满足 2^k ≥ n + k + 1，8 位数据至少 4 位校验位。
  • 提高 RAID 可靠性的措施：磁盘镜像、奇偶校验；条带化只提高性能不提高可靠性，增加 Cache 机制不提高可靠性。
  • 一次磁盘读写时间 = 寻道时间 + 旋转延迟时间 + 传输时间（+ 控制器延时）；平均旋转延迟为转半圈的时间。
  • 磁盘平均存取时间：寻道时间 + 1/(2r)（r 为转速）+ 传输时间。
  • 磁盘优点与缺点（王道 计组指导 3.4.1 p.111）：容量大、位价格低、记录介质可重复使用、记录信息可长期保存甚至脱机存档、非破坏性读出（读出时不需要再生）；缺点是存取速度慢、机械结构复杂、对工作环境要求较高。
  • 磁盘组成与结构（王道 计组指导 3.4.1 p.111）：硬盘由磁盘驱动器、磁盘控制器和盘片组成，控制器是与主机的接口（IDE、SCSI、ATA 等）；温彻斯特盘是一种可移动磁头固定盘片的硬盘；一块硬盘含若干记录面，每面分若干磁道，每条磁道分若干扇区，扇区（块）是磁盘读写的最小单位（按块存取）；磁头数 = 记录面数，柱面 = 不同记录面相同编号磁道的集合，扇区数 = 每条磁道的扇区数。
  • 磁盘地址与容量（王道 计组指导 3.4.1 pp.111–112）：地址 = 驱动器号｜柱面（磁道）号｜盘面号｜扇区号；例：4 驱动器 × 256 磁道 × 16 盘面 × 16 扇区 → 每扇区地址 18 位（2+8+4+4）；记录密度分道密度、位密度、面密度（面密度 = 位密度 × 道密度）；非格式化容量是记录表面可利用的磁化单元总数，格式化容量按记录格式算、比非格式化容量小。
  • 数据传输率与工作过程（王道 计组指导 3.4.1 pp.111–112）：转速 r 转/秒、每磁道容量 N 字节时，数据传输率 D_r = rN；硬盘主要操作是寻址、读盘、写盘，每操作对应一个控制字，先取控制字再执行；硬盘读写是串行的，同一时刻不能既读又写。
  • RAID 分级（王道 计组指导 3.4.1 p.112）：RAID0 无冗余无校验（条带化、提速但无容错）；RAID1 镜像（两盘当一盘、容量减半）；RAID2 用海明码纠错；RAID3 位交叉奇偶校验；RAID4 块交叉奇偶校验；RAID5 无独立校验的奇偶校验。
  • SSD 结构与磨损（王道 计组指导 3.4.2 pp.112–113；ddy OneNote 计组第3章）：一个 SSD 由一个或多个闪存芯片和闪存翻译层（FTL）组成，FTL 把 CPU 的逻辑块读写请求翻译成底层物理设备的读写控制信号，相当于磁盘控制器的角色；闪存由 B 块组成、每块由 P 页组成，页 512B~4KB、每块 32~128 页、块 16KB~512KB；数据以页为单位读写，只有整块擦除后才能写该页；某块约 10 万次重复写后磨损坏。
  • SSD 随机写慢的原因（王道 计组指导 3.4.2 p.113）：擦除块慢（1ms 级，比访问页高一个数量级）；写一页若要修改已有数据的页，须把该块所有有用页复制到一个新（已擦除）块中才能写；SSD 优点是无移动部件、随机访问比机械磁盘快得多、无机械噪声和震动、能耗低、抗震性好、安全性高。

2.3.3Cache 高速缓存真题 10 次

知识点

  • 三种映射地址划分：直接映射 [Tag | 行号 | 块内地址]；全相联 [Tag | 块内地址]；组相联 [Tag | 组号 | 块内地址]。
  • 行号 = 块号 mod 行数；组号 = 块号 mod 组数；标记 = 块号 ÷ 行数（组数）的商。
  • Cache 总位数 = 行数 ×（数据块位数 + Tag 位数 + 有效位 1 + 脏位 1（写回法）+ 替换位 log2 k）。
  • 比较器：直接映射 1 个，全相联为行数个，组相联为路数个；比较器位数均为标记位数。
  • 命中条件：标记相等且有效位为 1；有效位为 0 时标记相同也不命中。
  • 脏位只在回写法（写回法）出现，直写法不需要；替换算法位只在全相联/组相联出现，位数 = log2（路数）；直接映射不需要替换算法。
  • 命中率 H = Nc / (Nc + Nm)；平均访问时间 Ta = Tc + (1-H)·Tm；缺失时耗时 Tc + Tm。
  • 时间局部性：一条指令被执行后不久可能再次被执行；空间局部性：一个存储单元被访问后其附近单元很快被访问。
  • 指令 Cache 与数据 Cache 分离的主要目的是减少指令流水线资源冲突（结构冒险）。

  • 命中率题通用套路：算一块能放几个数据；只分析一个块，首个数据缺失、同块其余命中；确认每个数据访问几次；缺失率 = 1 ÷ 每块访问总次数。
  • 标记位不含块内地址；直接映射比较器只有 1 个，但位数是标记位数。
  • 脏位只在回写法出现；替换算法位只在全相联/组相联出现，位数 = log2(路数)。
  • 命中后按块内地址取一个数据送 CPU，不是把整块送给 CPU；缺失时整块调入 Cache 的同时把该地址数据送 CPU。

2.4.2寻址方式真题 8 次

知识点

  • 立即寻址：操作数直接在指令中，访存 0 次；直接寻址 EA = A，访存 1 次；间接寻址 EA = (A)，一次间接访存 2 次。

  • 基址寻址 EA = (BR) + A，访存 1 次，用于多道程序动态重定位（OS 面向）；变址寻址 EA = (IX) + A，访存 1 次，用于数组遍历（程序员面向）。
  • 相对寻址 EA = (PC) + A，访存 1 次，用于条件跳转；PC 是取指后的 PC（本条指令地址 + 指令长度）。
  • 偏移寻址 = 基址寻址、相对寻址、变址寻址；间接寻址不需要寄存器，不属于偏移寻址。
  • 先变址后间址：EA = ((I) + D)；变址寻址访问数组时，EA = 首地址 + 变址值 × 元素字节数。
  • 基址与变址的区别在"谁变"：基址 BR 不变、A 变，用于程序浮动；变址 IX 变、A 不变，用于数组。

口诀 / 技巧 / 易错点 （源B：06_第4章_指令系统）

  • 数组变址要乘元素大小：IX 只存下标时，EA = 首地址 + IX × 元素字节数。

2.5.1指令周期与执行过程真题 4 次

知识点

  • 指令周期 4 个阶段：取指周期 PC → MAR；主存 → MDR；MDR → IR；(PC)+1 → PC；间址周期 Ad(IR) → MAR；主存 → MDR；MDR → EA；执行周期 ALU 运算与 PSW 更新；中断周期保存断点、关中断、向量送 PC。
  • CPU 区分指令与数据的依据是指令周期的不同阶段（取指阶段取的是指令，执行阶段取的是数据）。
  • PC 位数由存储器字数决定：主存 4GB、字长 32 位 ⇒ 2^30 个字，PC 至少 30 位；IR 位数由指令字长决定，32 位指令 ⇒ IR 至少 32 位。
  • 时钟周期是 CPU 工作的最小时间单位，时钟周期的倒数为机器主频；指令周期由若干机器周期组成，一个机器周期又包含若干时钟周期。
  • 单周期处理器：所有指令的指令周期为一个时钟周期，CPI 为 1；要迁就最慢的指令，时钟频率较低。
  • 机器字长 = ALU 位数 = 通用寄存器位数。

口诀 / 技巧 / 易错点 （源B：07_第5章_中央处理器）

  • 取指微操作序列必须背下来：(PC)→MAR，M(MAR)→MDR，(MDR)→IR，提到取指就要会默写。
  • PC 自增的时机与增量：取指阶段一取出指令就更新 PC；增量是"指令占的地址单元数"，不是"字节数"，按字编址时要除以字长。
  • PC 位数 ≠ MAR 位数：指令按边界对齐时，PC 只需能区分"第几个指令槽"，位数比 MAR 少 log2(指令字节数) 位。
  • MAR 与 MDR 的位数不是一回事：MAR 由地址总线宽度/存储单元数决定，MDR 由存储字长/数据总线宽度决定。
  • 时钟周期是 CPU 最小时间单位，后面流水线还会反复用。

2.5.2数据通路真题 3 次

知识点

  • 数据通路：指令执行过程中数据所经过的路径，包括路径上的部件；ALU、通用寄存器、状态寄存器、Cache、MMU、浮点运算逻辑、异常和中断处理逻辑都属数据通路的一部分。
  • 数据通路不包括控制部件；数据流动路径由控制部件控制，控制部件按指令功能生成控制信号。
  • 单总线结构：一个时钟只能有一个 out 信号；两条微操作无逻辑先后且不共用同一组总线/部件时可合并到同一时钟。
  • ALU 无记忆功能，两个操作数之一须先进暂存器 Y，结果回总线须经暂存器 Z；实现单总线数据通路需要三态门与暂存器。
  • 执行"add xaddr, 3"类指令分取数、运算、写回三过程；Cache 直写方式下写回须同时写 Cache 与主存，至少访存 1 次。

口诀 / 技巧 / 易错点 （源B：07_第5章_中央处理器）

  • 数据通路大题答题模板：读图圈 out/in 部件 → 拆指令判寻址方式 → 写微操作"（源）→ 目的" → 配控制信号，最后检查每个时钟只有一个 out。
  • 能否合并到同一时钟的判据：两条微操作无逻辑先后且不共用同一组总线/部件 → 可合并；有逻辑先后或同一时钟出现两个 out → 必须分开。
  • 要访存 → 先把地址送 MAR；内存 ↔ CPU → 必经 MDR；两个操作数运算 → 必有一个先进暂存器 Y；结果回总线 → 必经 Z。
  • 单总线为什么必须加暂存器：ALU 无记忆功能，两端直连总线会互相覆盖；ALU 输出直连总线会反馈干扰自身输入。
  • Y 没有 out、Z 没有 in；信号以图为准，"图上有几个就写几个"，不要凭想象补信号。
  • MDRin 与 MDRinE 不能混：MDRinE 走数据总线（内存侧），MDRin/MDRout 走 CPU 内部总线。

2.5.4异常与中断机制真题 12 次

知识点

  • 中断是来自处理器外部的请求事件（如键盘输入、时钟到时、网络数据包到达）；异常（内中断）源自 CPU 执行指令内部的事件（如非法操作码、地址越界、算术溢出、缺页、陷入指令）。
  • 内部异常分三类：故障（fault）、陷阱（trap）、终止（abort）；除数为零和自陷（INT）会跳过中断指令，不返回发生异常的指令。
  • 中断隐指令（硬件自动完成，非真正指令）：关中断、保存断点与状态（PC/PSW）、寻找入口地址（中断向量查表）并送 PC。
  • 通用寄存器的保护由中断服务程序（软件）完成，不属中断隐指令；PC 和 PSW 由硬件自动压入内核栈。
  • 单级中断服务程序顺序：保护现场 → 中断事件处理 → 恢复现场 → 开中断 → 中断返回。
  • 多重中断：保护被中断进程现场时关中断，执行中断处理程序时开中断；中断屏蔽字按处理优先级设置，低优先级与自身写 1、高优先级写 0。
  • CPU 在一条指令执行结束的阶段采样中断请求信号，再决定是否响应；中断请求来自 CPU 以外的事件，异常发生在 CPU 内部。
  • 缺页中断发生在指令执行过程之中，处理后必须回到当前指令重新执行。

2.5.5指令流水线真题 9 次

知识点

  • 流水线时钟周期至少取最长功能段（或最长部件）的时间，再加流水段寄存器延时。
  • 流水线三公式：时间 T = (k + n - 1)Δt；吞吐率 TP = n / T，极限 1/Δt；加速比 S = nk / (k + n - 1)，极限 k 且永远达不到 k；效率 E = n / (k + n - 1)。
  • 结构冒险：多个指令同一周期争用同一硬件资源，解决靠插入气泡、指令与数据 Cache 分离。
  • 数据冒险（RAW/WAR/WAW）：后续指令依赖前面尚未写回的数据，解决靠数据旁路转发、编译器指令重排；数据旁路（转发）本身不会引起阻塞。
  • 控制冒险：分支跳转改变 PC 导致流水线断流，解决靠分支预测、延迟槽技术。
  • 超标量：在 CPU 中有一条以上的流水线，每个时钟周期可完成一条以上指令，其实质是以空间换时间；不缩短流水线功能段的处理时间。
  • 五段流水线：取指（IF）、译码/取数（ID）、执行（EX）、访存（MEM）、写回（WB）；"写后读"中间隔够 3 条指令即无冲突。
  • 理想 CPI 对比：单周期 CPI = 1（一条指令一拍做完）；多周期 CPI > 1（一条指令分好几拍）；基本流水线理想 CPI = 1（每拍完成一条）；超标量 CPI < 1（每拍完成多条）；IPC = 1/CPI。

口诀 / 技巧 / 易错点 （源B：07_第5章_中央处理器）

  • 流水线三类公式速记：T = (k+n-1)Δt；TP = n/T；S = nk/(k+n-1)；E = n/(k+n-1)。
  • 三类冒险一句话：结构冒险"抢同一个部件"；数据冒险"写没写完就要读"（RAW），能转发就转发，转不了就延迟，load-use 只能"等一拍再转发"；控制冒险"PC 还没定就取指"。
  • 时空图画法：每条指令一行、每时钟一列，五段依次填格；遇冒险画叉阻塞、后续段整体右移，"需多少时钟" = 最后一格列号。
  • 加速比达不到 k，S = nk/(k+n-1) < k，只在 n→∞ 时趋近 k。
  • 超标量 ≠ 超流水线：超标量是空间并行（多套硬件、CPI<1）；超流水线是时间上把段分得更细（CPI 仍 = 1，靠提高主频提速）。
  • 控制冒险的阻塞位置：条件转移阻塞到 MEM 之后（不是 EX 之后）；无条件转移在 EX 段就改 PC。
  • "写后读"不等于"一定冲突"，中间隔了 ≥3 条指令（对五段流水线）时不再有冒险。

2.6.1总线分类与性能指标真题 11 次

知识点

  • 总线带宽 = 总线工作频率 × 总线宽度（字节）；工作频率 = 时钟频率 × 每时钟传送次数。
  • 总线宽度是数据线位数（bit 或 B），总线带宽是"宽度 × 工作频率"（B/s），二者不是一回事。
  • 同步总线：通信双方采用同一个时钟信号；一次总线事务不一定在一个时钟周期内完成，时钟频率不一定等于工作频率。
  • 异步总线采用握手方式通信；半同步是"统一时钟 + 握手"的折中。
  • 突发（猝发）传输：在一个总线周期中传输多个存储地址连续的数据，一次传输一个地址和一批地址连续的数据。
  • 地址/数据线复用只是减少线的数量、节省成本，不能提高传输率。
  • 并行总线传输不一定比串行总线快：时钟频率提高到一定程度时，并行导线间干扰严重，串行总线反而可通过提高时钟频率提速。
  • QPI 总线是点对点全双工同步串行总线，设备可同时接收和发送信息。
  • 多总线结构：速率高的总线连高速设备，速率低的总线连低速设备；各总线通过桥接器相连。

口诀 / 技巧 / 易错点 （源B：08_第6-7章_总线与IO系统）

  • 总线宽度 ≠ 总线带宽：题目给"64 位总线"只说明宽度，必须再乘工作频率。
  • 同步定时 ≠ 异步定时：同步靠全系统统一时钟，不是各设备各自提供时钟；异步靠握手信号。

2.7.1I/O 接口概念与功能真题 4 次

  • I/O 指令实现的数据传送发生在 CPU 寄存器和 I/O 端口之间。

2.7.3程序中断方式真题 5 次

知识点

  • 程序中断方式：设备就绪后发起中断请求，数据通路为内存 ↔ CPU ↔ 设备，适用键盘、鼠标等字符型低速设备。
  • 中断服务程序在内核态下执行；用户程序在用户态，二者是不同的程序，靠中断向量跳转、靠中断返回指令返回断点。
  • 中断响应三步（中断隐指令，硬件）：关中断 → 保存断点和 PSW → 引出服务程序（入口送 PC）。
  • 中断处理六步（软件）：保护现场和屏蔽字 → 开中断 → 执行服务程序 → 关中断 → 恢复现场和屏蔽字 → 开中断、中断返回。
  • 外部中断包括不可屏蔽中断（NMI）和可屏蔽中断；NMI 不受中断标志位 IF 影响，即使关中断也会被响应。
  • CPU 响应中断须满足：中断源有中断请求、CPU 允许中断（开中断）、一条指令执行完毕且没有更紧迫的任务。
  • 若外设准备数据的时间小于中断处理时间，可能导致数据丢失（缓冲区被覆盖）。
  • 中断 I/O 方式每次中断可传一个数据缓冲寄存器的数据，如 32 位寄存器一次传 4B。

口诀 / 技巧 / 易错点 （源B：08_第6-7章_总线与IO系统）

2.7.4DMA 方式真题 3 次

知识点

  • DMA 方式：CPU 仅在预处理和结束时介入，数据通路为内存 ↔ 设备（直接传输，不经 CPU），适用磁盘、网卡等高速块设备。
  • DMA 传送三阶段：预处理（CPU 设置传送参数：起始地址、方向、个数）→ 数据传送（DMA 控制器直接控制总线完成）→ 后处理（DMA 发中断请求，CPU 执行中断服务程序做结束处理）。
  • DMA 传送前由 DMA 控制器请求总线使用权；数据传送阶段纯硬件完成，没有"DMA 传送程序"。
  • DMA 响应时机：在总线周期结束后（总线空闲）响应，不必等当前指令完成；DMA 不保存/恢复现场，因为它不是一个程序被打断。
  • 周期挪用 DMA：利用 CPU 不访问存储器的那些周期实现 DMA 操作，以字为单位；停止 CPU 访存方式以块为单位，整个数据块传送期间 CPU 不能访存。

口诀 / 技巧 / 易错点 （源B：08_第6-7章_总线与IO系统）

  • DMA 过程：预处理（CPU 设起始地址/方向/个数）→ 数据传送（硬件，块/字）→ 后处理（中断，CPU 校验）。
  • DMA 传块，周期挪用一个字。
  • DMA 与中断响应时机不同：中断在一条指令执行结束后响应；DMA 在总线周期结束后响应。
  • DMA 没有"DMA 传送程序"，数据传送阶段纯硬件完成，只有预处理和后处理需要 CPU。

  • 多道程序设计：多个程序同时放入内存、交替在 CPU 上运行，共享系统软硬件资源；一道程序因 I/O 暂停时 CPU 立即转去运行另一道程序，I/O 设备与 CPU 并行工作靠中断技术实现。
  • 批处理系统没有交互能力（作业执行时用户无法干预，只能事先编制作业控制说明间接干预）；分时系统正为交互而发展出来；批处理系统分为单道批处理系统和多道批处理系统。
  • 多道程序系统的优点：CPU 利用率、系统吞吐量、I/O 设备利用率提高；代价：组织作业和切换作业要付出额外开销。
  • 多任务操作系统的特点是并发和并行；多个任务须互斥访问共享资源，须对共享资源加以保护；多 CPU 不是多任务操作系统的必备硬件。

口诀 / 技巧 / 易错点 （源B：01 第1章 操作系统概述）

  • “多道程序数 ↑，CPU 利用率不会无限 ↑”（切换有开销）；“批处理有交互性”——错，单道、多道批处理都没有交互性，有交互性的是分时和实时。
  • “并行 = 并发”——错：单 CPU 上多个程序只能并发，CPU 与 I/O、多个 I/O 设备之间才是并行；“同时访问 = 真正同时”——错，同时访问宏观同时、微观仍是交替。

  • 2018-23：多任务操作系统具并发与并行特点、须保护共享资源，不必运行在多 CPU 平台。

3.1.2操作系统的运行环境真题 16 次

知识点

  • 内核态（管态，Ring 0）可执行特权指令与非特权指令；用户态（目态，Ring 3）仅允许执行非特权指令。
  • 用户态 → 内核态的唯一途径是通过中断 / 异常 / 系统调用；内核态 → 用户态通过修改程序状态字 PSW 主动降级返回。
  • 系统调用是操作系统提供给应用程序的接口：用户在用户态调用，具体的系统调用服务程序在内核态执行；不同操作系统的系统调用接口并不统一。
  • 特权指令包括：有关 I/O 设备操作的指令、有关访问程序状态的指令、存取特殊寄存器指令、清内存、关中断等指令。
  • 中断处理：断点（PC）与程序状态字 PSW 由硬件（中断隐指令）保存，通用寄存器内容由操作系统保存；时钟中断处理与时间有关的信息并决定是否执行调度程序。

口诀 / 技巧 / 易错点 （源B：01 第1章 操作系统概述）

  • 三对概念成对背：用户程序 ↔ 非特权指令 ↔ 用户态；内核程序 ↔ 特权指令 ↔ 内核态。
  • 状态转换口诀：“进内核靠中断异常，出内核靠返回指令；trap 在用户态，改模式靠硬件”。
  • 系统调用四步：“传参 → 陷入 → 处理 → 返回”，与“函数调用”只差“跨特权级”。
  • 九个步骤口诀：“关、存、引（硬件三步）→ 保、析、处、恢、开、返（OS 六步）”。
  • 内外中断判别法：问“这事是不是当前这条指令自己惹出来的？”是 → 内中断（异常），不是（外部设备/时钟/电源）→ 外中断。
  • 故障/自陷/终止判别法：能修好重执行 → 故障；主动陷入、执行完往下走 → 自陷；修不了、程序死 → 终止。
  • 易错：“内核态只能执行特权指令”错，内核态特权与非特权指令都能执行；“trap 是特权指令/在内核态执行”错，trap 是非特权指令、在用户态执行；“保存断点是操作系统做的”错，保存断点（PC、PSW）、关中断、引出中断服务程序都由硬件完成，保存通用寄存器才是 OS 做；“把 CPU 模式改为内核态是 OS 做的”错，由硬件完成；“缺页是外中断”错，缺页属内中断（故障），可修复、返回当前指令重执行；“除零是自陷”错，除零是故障（不可修复，常终止程序）；“printf 是系统调用”错，printf 是库函数，内部封装 write 系统调用。

3.1.3操作系统的结构与引导真题 2 次

知识点

  • 操作系统引导 7 步：通电置 PC（指向 ROM 中 BIOS）→ 硬件自检 POST → 读 CMOS 确定启动设备 → 加载主引导记录 MBR（查磁盘分区表 DPT）→ 定位活动分区 → 加载分区引导记录 PBR → 运行 Bootloader 装载内核入 RAM。
  • 计算机开机后，操作系统最终被加载到 RAM。
  • 操作系统初始化过程中创建中断向量表（CPU 据中断号查表跳转到对应中断处理程序）；硬盘逻辑格式化时创建分区表，并在每个分区初始化文件系统、创建根目录与索引结点表。

  • 大内核 vs 微内核：大内核性能高（模块间直接函数调用）、可靠性低；微内核只留进程通信、低级调度、中断处理在内核，可靠性高、性能低；典型：Linux/UNIX 是大内核，Mach/QNX 是微内核。
  • 引导流程框架：CPU 加电 → 执行 BIOS 自举程序 → 读主引导记录 MBR → 执行分区引导记录 → 加载活动分区的引导程序 → 装入操作系统内核并初始化。

3.2.1进程与线程真题 12 次

知识点

  • 进程状态机转换：就绪态 → 运行态（被调度选中获 CPU 时间片）；运行态 → 就绪态（时间片耗尽或被更高优先级进程抢占）；运行态 → 阻塞态（主动请求某一资源未满足，如等待 I/O 或执行 P 操作）；阻塞态 → 就绪态（所等待事件发生，如 I/O 完成或被 V 操作唤醒）。
  • 处理器管理的关键技术包括进程与线程调度、进程同步与互斥（信号量机制、管程）、进程间通信 IPC、死锁的预防/避免（银行家算法）/检测与解除（源A第 1 章全景表）。
  • 进程的组成与标识（ddy OneNote 操作系统第2章）：进程 = 程序 + 数据 + PCB；进程实体（进程映像）= PCB + 程序段 + 相关数据段；PCB（进程控制块）是进程存在的唯一标识，一个进程必然有一个 PCB，进程消失 PCB 也随之消失；PCB 包含进程当前状态（new、ready、running、waiting/blocked 等）、CPU 状态信息（进程被切换时 CPU 状态保存在相应 PCB 中以便恢复）。
  • PCB 的组织（ddy OneNote 操作系统第2章）：链接方式——把同一状态的 PCB 链成一个队列，不同状态对应不同队列；也可把阻塞态进程的 PCB 按阻塞原因排成多个阻塞队列。
  • 线程与进程的比较（王道 OS 指导第 2 章 p.43）：引入线程后，进程只作为除 CPU 外的系统资源的分配单元，线程作为处理机的分配单元；线程是独立调度的基本单位，同一进程内线程切换代价远低于进程切换（同一进程内线程切换不引起进程切换，跨进程的线程切换会引起进程切换）；进程是拥有资源的基本单位，线程不拥有系统资源（仅有一点必不可少、能保证独立运行的资源），但可访问隶属进程的系统资源（同一进程所有线程共享相同地址空间）；每个进程有独立地址空间和资源，某进程的线程对其他进程不可见；创建/撤销进程的系统开销明显大于创建/撤销线程；多线程进程可把多个线程分配到多个处理机上执行，单线程进程只能运行在一个处理机上。
  • 线程的属性（王道 OS 指导第 2 章 p.43）：线程是轻型实体，不拥有系统资源，但每个线程有唯一标识符和一个线程控制块（记录线程执行的寄存器和栈等现场状态）；不同线程可执行相同程序；同一进程各线程共享该进程拥有的资源；线程是处理机的独立调度单位，单 CPU 下各线程交替占用 CPU，多 CPU 下各线程可同时占用不同 CPU；线程在生命周期内经历阻塞态、就绪态和运行态等状态变化。
  • 线程模型（ddy OneNote 操作系统第2章）：多对一模型（多个用户线程对应一个内核线程）、一对一模型（一个用户线程对应一个内核线程）、多对多模型。
  • 进程间通信 IPC 与进程控制（ddy OneNote 操作系统第2章）：进程之间不能直接交换数据，可利用 OS 提供的共享文件（如管道）、信息传递系统、共享存储区进行通信；进程创建：申请空白 PCB、填写控制和管理信息、插入就绪队列；进程终止：查找 PCB、从队列删除；进程阻塞：找到 PCB、插入阻塞队列；进程唤醒：在事件阻塞队列中找到相应 PCB；用户登录成功与启动程序执行导致创建新进程，设备分配不导致创建进程。

口诀 / 技巧 / 易错点 （源B：02 第2章 进程线程与调度）

  • 状态判定三步：先问“它有没有 CPU”→ 有 CPU 才可能“主动阻塞”；再问“它缺什么”→ 只缺 CPU 是就绪，缺事件是阻塞；最后问“谁动的”→ 自己动 = 主动（运行 → 阻塞），别人动 = 被动（阻塞 → 就绪）。
  • 不可能转换四连：就绪不阻塞、阻塞不运行、创建不运行、挂起不运行。

3.2.2处理机调度真题 18 次

知识点

  • FCFS（先来先服务）：非抢占，算法简单、公平，长作业有利、短作业不利（护航效应）。
  • SJF/SPF（短作业优先）：抢占与非抢占均可，平均等待时间/周转时间最短，会导致长作业饥饿。
  • HRRN（高响应比优先）：非抢占，兼顾长短作业、无饥饿；响应比 R =（等待时间 + 服务时间）/ 服务时间 ≥ 1。
  • RR（时间片轮转）：抢占，响应时间极佳；时间片过大退化为 FCFS，过小则切换开销剧增。
  • 多级反馈队列：抢占，综合最优、兼顾长短与交互；各队列时间片递增，进程用完时间片自动降级。
  • 可引起进程调度的事件：中断处理结束、进程阻塞、进程执行结束、进程时间片用完；不适合调度的情况：在处理中断的过程中、进程在操作系统内核程序临界区中、其他需完全屏蔽中断的原子操作过程中。

口诀 / 技巧 / 易错点 （源B：02 第2章 进程线程与调度）

  • 算周转四步模板：画时间轴 → 按规则填每段区间（抢占式标“剩余时间”）→ 读每个进程的完成时刻 f → 周转 T = f − a，带权周转 W = T/s，最后求平均；带权周转可以 > 10。
  • 饥饿判断：SJF、优先级会饥饿，FCFS、HRRN、RR 不会。
  • RR 推演技巧：每次时间片结束时，先把“这一段时间内新到达的进程”按到达顺序入队，再把“刚被剥夺的进程”挂到队尾。
  • MLFQ 推演技巧：先写清三条规则（新进程入 Q1、用完时间片降级、高队列非空不跑低队列），每换一个队列标一次剩余时间。
  • 抢占式 SJF 的比较对象是“新到进程的服务时间”与“当前进程的剩余时间”，不是原始服务时间。
  • 易错：时间片 q 过大退化为 FCFS、过小则上下文切换开销占比过高，不能说“q 越小越好”；优先级方向要看清题目（数值大还是小代表优先级高）；等待时间是多段之和，响应时间只算第一次；带权周转时间的分母是服务时间，不是周转时间。

3.2.3同步与互斥真题 9 次

知识点

  • 处理器管理的关键技术包括进程同步与互斥：信号量机制、管程（源A第 1 章全景表）。
  • 进程状态转换与 PV 操作的联系：运行态 → 阻塞态可由执行 P 操作（请求资源未满足）引起；阻塞态 → 就绪态可由 V 操作唤醒引起。
  • 管程是由一组数据以及定义在这组数据之上的操作组成的软件模块：局部于管程的数据只能被管程内过程访问；进程只有通过调用管程内过程才能进入管程访问共享数据；每次仅允许一个进程在管程内执行某个内部过程；管程既能实现进程间互斥，也能实现进程间同步。
  • 条件变量是管程内用于进程同步的特殊变量，作用类似信号量机制中的信号量；进程执行 x.wait() 时阻塞并挂到条件变量对应的阻塞队列上、释放管程使用权，执行 x.signal() 时唤醒对应阻塞队列队头进程。
  • 记录型信号量（王道 OS 指导 2.3 p.94；ddy OneNote 操作系统第2章）：不存在"忙等"现象；除代表资源数目的整型变量 value 外，再加一个进程链表 L 链接所有等待该资源的进程；wait(S) 时 S.value--，若 < 0 则调用 block 原语自我阻塞、放弃处理机并插入等待队列 S.L（"让权等待"）；signal(S) 时 S.value++，若 ≤ 0 则调用 wakeup 原语唤醒 S.L 中第一个等待进程。
  • 整型信号量与记录型信号量的区别（ddy OneNote 操作系统第2章）：整型信号量只是一个表示资源数目的整型量 S；记录型信号量引入阻塞机制、可让权等待，消除忙等待。
  • 利用信号量实现同步（王道 OS 指导 2.3 p.94）：设 S 为 P1、P2 同步的公共信号量、初值为 0；P2 的语句 y 要用 P1 的语句 x 的结果，则 P1 执行完 x 后 V(S)，P2 执行 y 前 P(S)；若 P2 先执行到 P(S) 时 S 为 0，P 操作把 P2 阻塞并放入阻塞队列。

口诀 / 技巧 / 易错点 （源B：03 第2章 同步互斥与死锁）

  • 信号量定值口诀：资源数 = 信号量初值；mutex 恒为 1；同步的“资源”还没产生，初值 0；系统本来就有存货（信箱已有 X 封），初值就写 X。
  • 同步写法口诀：前 V 后 P，先发生的动作后面 V，后发生的动作前面 P，初值 0。
  • 互斥写法口诀：PV 夹临界区，一锁一开成对出现；P = 加锁，V = 解锁。
  • 生产者消费者 PV 顺序口诀：先资源、后互斥（empty/full 在前，mutex 在后）；V 的顺序无所谓，P 的顺序要命。
  • 信号量值速读：值为正 → 剩几个资源；值为负 → 几个进程在等；值 = 初始值 − 已被拿走数。
  • 易错：生产者消费者两个 P 写反（先 P(mutex) 后 P(empty)）会死锁；同步信号量初值写成 1 则同步失效，同步初值必须是 0；信号量为负表示有进程在等待，不是还剩资源；记录型信号量 P 里判 < 0、V 里判 <= 0。
  • 管程（源B 03 §五，教材补充概念级）：管程把共享数据结构 + 对该结构的所有操作 + 同步机制封装成模块，管程内过程互斥执行由编译器保证；条件变量没有值，signal 时若无进程等待则信号丢失。

3.2.4死锁真题 12 次

知识点

  • 死锁产生 4 大必要条件：互斥使用、不可剥夺、请求并保持、循环等待。
  • 银行家算法：在分配资源前先预判分配后系统是否处于安全状态（能否找到至少一个合法安全序列），若安全才正式分配。
  • 死锁处理三策略：死锁预防（破坏四个必要条件中的一个或几个）、死锁避免（银行家算法）、死锁检测和解除。
  • 破坏循环等待条件一般采用顺序资源分配法：给系统资源编号，规定每个进程必须按编号递增顺序请求资源。

口诀 / 技巧 / 易错点 （源B：03 第2章 同步互斥与死锁）

  • 银行家算法三步：Need = Max − Allocation；Available = 总量 − ΣAllocation；拿 Need 与 Work 逐项比，全都 ≤ 才可推进，推进后 Work += Allocation。
  • 银行家校验口诀：全部进程跑完，Work 必然回到资源总量；不相等 = 算错。
  • 死锁最小进程数公式（同类资源，每进程最多需 m 个，共 R 个）：K_min = ⌊(R−1)/(m−1)⌋ + 1；例 R=8、m=3 → ⌊7/2⌋+1 = 4。
  • 预防 vs 避免的字眼抠死：破坏四个必要条件 = 预防，银行家算法 = 避免。
  • 易错：资源分配图有环不一定死锁，只有每类资源单实例时有环必死锁；“不安全状态”和“死锁”不同，不安全只是可能死锁；死锁进程必处于阻塞态，饥饿进程可能在就绪态，死锁至少两个进程；银行家算法算错 Work 的常见原因是进程完成后只加 Need 而不是把已分配的全部资源加回 Work。

3.3.1连续与非连续分配真题 7 次

知识点

  • 基本分页：无外部碎片，有页内碎片；逻辑地址 → 页号 + 页内偏移；内存利用率高，无逻辑独立性。
  • 基本分段：无内部碎片，有外部碎片；逻辑地址 → 段号 + 段内偏移；方便代码共享与保护，易产生碎片。
  • 段页式管理：无外部碎片，仅段内最后一页有内部碎片；地址变换为段号 → 段表 → 页表 → 物理块，综合优势、访存开销大（需 3 次访存）。

口诀 / 技巧 / 易错点 （源B：04 第3章 内存管理）

  • 分页是“拼”、分段是“加”：分页把页号直接替换成页框号、偏移不变，分段必须基址 + 偏移；段表项须存段长 + 基址，页表只存页框号。
  • 偏移位数速查：页大小 4KB → 12 位 → 十六进制 3 位；十六进制地址从右往左切 3 位即得偏移，左边剩下全是页号。
  • 十进制就除、二进制就切：A ÷ 页大小，商 = 页号、余 = 偏移；二进制/十六进制直接截取低位。
  • 物理地址 = 页框号 × 页大小 + 偏移；4KB 页时就是“页框号后面补 3 个十六进制 0，再加偏移”。
  • 碎片口诀：单一有内无外、固定有内无外、动态有外无内、分页有内无外、分段有外无内。
  • 算法口诀：首次从头、邻近接着找、最佳容量升、最坏容量降；只有首次/邻近按地址，最佳/最坏按容量。
  • 易错：越界条件是页号 ≥ 页表长度（页号 = 页表长度也越界），分段同理段内偏移 ≥ 段长就越界；最佳适应“名为最佳、实际最差”，每次留下极小剩余块、产生大量外部碎片；回收必须与相邻空闲区合并，前后都空闲要三者合并；段表必须“段长 + 基址”，页表只存页框号。

3.3.2虚拟内存管理真题 20 次

知识点

  • 4 大页面置换算法：OPT 淘汰以后永不使用或最长时期内不用的页面，是理论上限、无法实现；FIFO 淘汰最早进入内存的页面，会产生 Belady 异常（分配物理块数增多但缺页率反增）；LRU 淘汰最近最长时间未被访问的页面，性能最接近 OPT、硬件开销大；CLOCK 循环指针扫描、检查访问位 u 与修改位 m，是实际操作系统最常采纳的折中方案。
  • 虚拟存储器建立在离散分配的内存管理方式基础上：请求分页存储管理、请求分段存储管理、请求段页式存储管理；虚拟存储器容量既不受外存容量限制也不受内存容量限制，由 CPU 的寻址范围决定。
  • 抖动现象：刚刚被换出的页很快又要被访问，又要换出其他页，如此频繁置换页面，以致大部分时间都花在页面置换上；撤销部分进程可减少所用页面数、防止抖动。
  • 对换功能的操作系统把外存分为文件区（存放文件）与对换区（存放从内存换出的进程）。

口诀 / 技巧 / 易错点 （源B：05 第3章 虚拟内存）

  • 置换算法一句话：OPT 看未来最远，LRU 看过去最久，FIFO 看进来最早，CLOCK 看访问位转圈。
  • 字段口诀：请求分页页表 = 基本 2 个 + “存、访、改、外”4 个新增字段。
  • 缺页链口诀：“判界 — 查快 — 查表 — 看位 — 中断 — 存场 — 找址 — 腾框 — 调入 — 改表 — 重执 — 拼址”。
  • 改进型 CLOCK 淘汰序：把（A,M）当二进制数，00 < 01 < 10 < 11，从小到大淘汰。
  • 缺页次数 vs 置换次数：还有空闲页框 → 只缺页不置换；页框全满 → 缺页必置换。
  • 易错：缺页中断是故障，在指令执行期间产生，必须重新执行当前指令（返回地址不是下一条指令）；OPT 与 LRU 方向弄反，OPT 往后看（未来），LRU 往前看（过去）；以为页框越多缺页一定越少，FIFO 有 Belady 异常；被淘汰页修改位 = 1 必须写回外存，= 0 才能直接丢弃；驻留集是“分给你几个”，工作集是“你实际要用几个”，要求驻留集 ≥ 工作集。

  • DMA 传输过程：主机向内存写入 DMA 命令块，向 DMA 控制器写入该命令块的地址并启动 I/O 设备；CPU 继续其他工作，DMA 控制器直接操作内存总线传输；传输完成后 DMA 控制器中断 CPU。
  • 设备驱动程序由厂家提供：主机须先安装驱动程序才能使用设备；驱动程序负责初始化设备（如将设备控制器中的寄存器初始化）；设备的读/写操作本质是在设备控制器和主机之间传送数据，只有厂家提供的驱动程序能控制设备的读/写操作。
  • 四种 I/O 控制方式（王道 OS 指导 5.1.2，pp.287–289）：
  • 程序直接控制（轮询）：CPU 每读一个字都要循环查 I/O 控制器状态位，确认数据就绪才取数、再存入内存；全程 CPU 忙等，CPU 与外设只能串行，CPU 利用率极低。优点只有实现简单。
  • 中断驱动：外设备好数据后主动发中断，CPU 收到中断才停下当前工作、保存现场、取一个字存入内存、恢复现场；发完读命令后 CPU 可去做别的事。但每个字都要经过 CPU 中转、都要中断一次，频繁读写（如磁盘）时 CPU 仍被大量中断占用。
  • DMA：在外设与内存之间开一条不经过 CPU 的直通数据路；CPU 只在传送开始（下发命令、设置内存地址寄存器 MAR 与数据计数器 DC 初值、启动 DMA 控制器）与结束（DMA 控制器发中断报告完成）时干预，整块数据的搬运由 DMA 控制器负责；基本单位是数据块；每个 DMA 控制器对应一台设备；典型用于磁盘这类块设备。DMA 控制器内有四类寄存器：命令/状态寄存器 CR、内存地址寄存器 MAR、数据寄存器 DR、数据计数器 DC。
  • 通道：专管 I/O 的处理机，是 DMA 的发展；CPU 只需发一条 I/O 指令（给出通道程序首地址与要访问的设备），通道从内存取通道程序并执行，完成后才中断 CPU；干预单位从「一个数据块」放宽到「一组数据块及有关控制」；CPU、通道、I/O 设备三者可并行；一个通道可控制多台设备；代价是实现复杂、需专门硬件。（超纲，了解即可——王道书标 *，已在最新大纲删除）
  • 递进关系：CPU 干预越来越少（每字轮询 → 每字中断 → 每块首尾干预 → 每组首尾干预），数据单位越来越大（字 → 字 → 数据块 → 数据块组），并行度越来越高（串行 → CPU 与外设部分并行 → CPU 与 DMA 并行 → CPU、通道、I/O 三者并行）。
  • DMA 与中断的关键区别：中断方式是每个数据需要传输时都中断 CPU，且传送在中断处理时由 CPU 控制完成；DMA 是一批数据全部传完才中断一次，且传送由 DMA 控制器控制完成。

4.1.2三种交换方式真题 1 次

知识点

  • 电路交换：建连→传输→释放，独占通路、直达，中间不存储转发；完成时间最短。
  • 报文交换：整报文存储转发，逐跳收全再发；完成时间最长，不失序。
  • 分组交换：分组（首部 + 数据段）存储转发，可流水线并行；可能失序、重复，需编号重组。
  • 分组交换总时延 = (N + k − 1) × T（N 分组数，k 段数，T 单跳发送时延）；分组数按净荷算（分组长 − 首部）。
  • 报文交换总时延 = k × T_报文；电路交换 = 建立时间 + 1 个发送时延。
  • 完成传输时间：电路交换 < 分组交换 < 报文交换；只有分组交换会乱序。

口诀 / 技巧 / 易错点 （源B：第1章 计算机网络体系结构）

  • 流水线万能式：总时延 = (N + k − 1) × T；记法“先把 N 个全发出去，再让最后一个走完全程”。
  • 三问定式：①分几组（用净荷算）→②单跳 T 是多少→③末分组还要走几跳；列式前先画甘特图。
  • 分组数用错分母是坑：分组数 = 总数据量 ÷ 每分组净荷，不是 ÷ 分组总长。
  • 字节忘乘 8 是坑：L 必须以 bit 代入；速率用 10⁶、容量用 2²⁰，题干注明进制时听题干的。

  • (N+k−1)T 成立前提是各跳速率相同且无处理/排队停顿；速率不同时末分组每跳分别算。

4.2.1通信基础真题 6 次

知识点

  • 奈氏准则（无噪声极限）：C = 2W log₂V（b/s），W 带宽，V 信号状态数。
  • 香农公式（有噪声极限）：C = W log₂(1 + S/N)（b/s）；信噪比 dB = 10 log₁₀(S/N)。
  • 两条件都给时分别计算，取两者最小值作为极限数据传输速率。
  • 波特率与比特率：比特率 = 波特率 × log₂V；码元速率上限 2W 只是波特率上限。
  • QAM 状态数 V = 相位数 × 每相位幅度数。
  • 信号传播速度不影响信道数据传输速率（影响传播时延）。

口诀 / 技巧 / 易错点 （源B：第2章物理层与第3章链路层上）

  • 先问三句再动笔：①单位是 Hz 还是 bit/s？②问波特率还是比特率？③有噪声吗？
  • 有噪声→香农，无噪声→奈氏，条件全给→取小。
  • dB 除 10 再取 10 的幂：30 dB → S/N = 10³ = 1000；log₂速记 1000 ≈ 10。
  • QAM 求 V：相位数 × 每相位幅度数；QAM 求比特率：波特率 × log₂(状态数)。
  • 把 2W 当比特率是错的；香农公式前面没有系数 2；dB 必须先换算成 S/N 倍数再代入。
  • ASK 的“4 个幅值”是 4 种状态（V = 4，2 bit/码元），不是 4 bit/码元。

4.3.1组帧与差错控制真题 1 次

知识点

  • 奇偶校验：码距 d = 2，仅检奇数个比特错，偶数个错漏检，无纠错与定位能力。
  • CRC：检错能力强（单比特、双比特、奇数个错及长度 ≤ r 的突发错全检出），仅检错不纠错；生成多项式须含常数项 1。
  • CRC 计算：数据后补 r 个 0，模 2 除得余数 FCS 拼接发送；接收端余数为 0 接收、非 0 丢弃。
  • 海明码：码距 d = 3，检 2 错、纠 1 错；校验位位数满足 2^r ≥ k + r + 1，校验位放在 2^(i−1) 位置。
  • 海明码伴随式非 0 时，其十进制值直接对应出错位编号，取反即修复。
  • HDLC 帧格式：标志 F（8 位，01111110）｜地址 A（8 位）｜控制 C（8 位）｜信息 Info（可变）｜帧检验序列 FCS（16 位，CRC）｜标志 F。FCS 校验区间是地址 A + 控制 C + 信息 Info；透明传输区间还包括 FCS。
  • 零比特填充：发送端扫描数据比特流，每遇到连续 5 个 1 就在其后插入一个 0；接收端找到标志 F 定界后扫描比特流，每遇到 5 个连续的 1 就删掉其后的一个 0，还原原数据。这样数据里即使出现 01111110 也不会被误认成标志。
  • HDLC 与 PPP 的区别：PPP 面向字节、HDLC 面向比特；PPP 帧比 HDLC 多一个 2 字节协议字段（0x0021 表示 IP 数据报）；PPP 不用序号与确认（只保证无差错接收），HDLC 信息帧用编号与确认、能提供可靠传输。
  • HDLC 三种帧类型（按控制字段最前面两位划分）：信息帧 I（传数据，用编号与确认）、监督帧 S（流量控制与差错控制）、无编号帧 U（链路管理，如建链/断链）。（王道 计网指导 p.128 试题精选 Q12）
  • HDLC 属超纲（王道书标 *，已在最新大纲删除），但 2013 年真题考过，收录合理。（王道 计网指导 3.2.3 p.70、*3.7.3 pp.124–125；ddy OneNote 计网第3章）

4.3.2流量控制与滑动窗口机制真题 8 次

知识点

  • 停止-等待：W_T = 1，W_R = 1，单帧逐一确认；序号比特数 n ≥ 1。
  • GBN：W_T > 1，W_R = 1，累计确认，超时重传已发未确认的全部帧；W_T ≤ 2^n − 1。
  • SR：W_T > 1，W_R > 1，逐帧非累计确认，仅重传出错帧；W_T + W_R ≤ 2^n，通常 W_T = W_R = 2^(n−1)。
  • 信道利用率：停等 U = t_tx / (t_tx + 2 × t_prop + t_ack)；流水线 U = min(1, W_T × t_tx / T_cycle)。
  • 最高利用率判据：W_T ≥ ⌈T_cycle / t_tx⌉；帧长给范围时按最短帧算（所需窗口最大）。
  • 确认帧若与数据帧等长，须计入确认帧发送时延；若忽略则 t_ack ≈ 0。

口诀 / 技巧 / 易错点 （源B：第2章物理层与第3章链路层上）

  • 三协议窗口一句话：停等“一一对应，1 位编号”；GBN“收窗为 1，发窗占满减一”（2^n−1）；SR“收发对半分”（2^(n−1)）。
  • 判协议：出现“累计确认”→GBN；出现“缓存失序帧”“仅重传出错帧”→SR。
  • GBN 重传个数：收到最大确认号 m 后，超时重发“从 m+1 到已发送的最后一帧”。
  • SR 重传个数：只数“已超时/已判错”的帧，未超时的不管。
  • GBN 收到 0、2、3 的确认却重发 1~3 是错的：累计确认意味着 3 号确认已包含 0~2，应从 4 号起重发。
  • 求 n 时用 2^n ≥ K 而不是 2^n − 1 ≥ K（GBN），边界上会差一位。
  • 2τ 只乘了一次 τ 是错的：题目给“单向传播时延”必须乘 2；给 RTT 则直接用。

  • CSMA/CD：先听后发、边发边听，冲突停发；用于有线以太网（IEEE 802.3），MAC 层无确认。
  • 争用期 = 2τ（τ 为单程传播时延）；最短帧长 = 2τ × 数据传输速率；传统以太网最短帧长 64 B。
  • 二进制指数退避：k = min(重传次数, 10)，从 [0, 2^k − 1] 中随机选 r，退避 r × 2τ；重传 16 次仍失败则报错。
  • CSMA/CA：用于无线局域网（IEEE 802.11），碰撞避免，必须有 ACK；无线不能用 CD（信号衰减大、无法边发边听，存在隐蔽站）。
  • CSMA/CA 用 RTS/CTS 预约信道，用 NAV 虚拟载波监听；IFS 优先级：SIFS 最短最高，DIFS 最长最低。
  • 随机访问（ALOHA、CSMA）可能发生冲突；信道划分与轮询访问不会发生冲突。
  • 冲突域隔离：集线器/中继器不能隔离，交换机/网桥能隔离冲突域、不能隔离广播域，路由器两者都能隔离。

口诀 / 技巧 / 易错点 （源B：第3章 数据链路层下）

  • 十六字诀：先听后发→边听边发→冲突停发→随机重发。
  • 最小帧长三步法：①单位全换成 bit 与 bit/s；②2τ = L/V 或 L = 2τV；③有中继器/集线器时把设备延迟并入 τ 再乘 2。
  • 退避三句：k = min(n, 10)；r ∈ [0, 2^k−1]；退避 = r × 2τ；10 Mb/s 以太网 2τ = 51.2 μs 直接背。
  • CA 时序记法：只有第一个是 DIFS，后面全是 SIFS；“先 DIFS，再退避，RTS→CTS→数据→ACK”。
  • 域的口诀：集线器什么都不隔；交换机隔冲突不隔广播；路由器两个都隔。
  • 2τ 与 τ 混用是错的：争用期是往返 2τ；求距离时 L = V·2τ，解出的 2τ 要除 2 才是单程时延。
  • k 的截断是坑：第 11、12、16 次重传 k 都是 10，不是 11/12/16。
  • CSMA/CD 无法用于无线：不是“无线不想用”，而是检测不到（发射信号淹没接收信号 + 隐藏站）。
  • DIFS 与 SIFS 长短写反就全错：SIFS 最短（优先级最高），DIFS 最长。

4.3.4局域网与交换机真题 9 次

知识点

  • 以太网交换机是多端口网桥，工作在数据链路层；转发决策用目的 MAC 地址（自学习用源地址）。
  • 以太网 MAC 协议：无连接，不对数据帧编号、不要求对方确认，尽最大努力交付（不可靠服务）。
  • 以太网帧：目的 MAC 6 B + 源 MAC 6 B + 类型 2 B + FCS 4 B = 18 B 头尾；最小帧 64 B，最大帧 1518 B。
  • 直通交换：只收目的 MAC（6 B）即转发；存储转发：收完整帧再转发。
  • 交换机转发表查不到目的地址时泛洪（除入端口外所有端口）；查到则只从对应端口转发。
  • 交换机隔离冲突域、不隔离广播域；只有路由器（或 VLAN）能隔离广播域。
  • 802.11 数据帧地址：地址 1 = 当前接收方，地址 2 = 当前发送方，地址 3 = 剩下的那个；To AP 帧的地址 1 是 AP 的 MAC（BSSID）。
  • CSMA/CA 是唯一对正确接收的数据帧进行确认的 MAC 协议（CDMA 属物理层，CSMA/CD 无确认）。
  • 源A本章 md 未单列交换机/网桥小节（见汇报）；以上交换机要点据源B第3章与源A真题解析。
  • 网桥（王道 计网指导 3.8.1 p.128）：工作在链路层的 MAC 子层；两个或多个以太网通过网桥连接后成为一个覆盖范围更大的以太网，原来的每个以太网称为一个网段；网桥使以太网各网段成为隔离的碰撞域（冲突域），各网段相对独立、一个网段的故障不会影响另一个网段；网桥必须具有路径选择功能，收到帧后决定正确路径；转发规则：是另一网段地址则转发，是本网段地址则丢弃（源站和目的站同一网段，目的站能直接收到）；注：最新大纲已删除网桥内容，但历年真题有所涉及。
  • 交换机特点（王道 计网指导 3.8.2 pp.128–129）：本质上是多端口网桥，工作在数据链路层；每个端口直接与单台主机相连（网桥端口往往连一个网段），一般工作在全双工；能同时连通多对端口，每对通信主机像独占通信媒体那样无碰撞地传输数据；即插即用设备，转发表通过自学习算法自动逐渐建立；独占传输媒体的带宽，N 个端口的总容量为 N×10Mb/s（共享式以太网每个用户平均只有总带宽的 1/N）；可方便实现 VLAN，VLAN 不仅隔离冲突域、而且隔离广播域。
  • 直通与存储转发（王道 计网指导 3.8.2 p.129）：直通式只检查帧的目的地址、接收后几乎马上转发，速度快但缺乏智能性和安全性、无法支持不同速率端口的交换；存储转发式先把帧缓存到高速缓存器并检查帧是否正确，确认无误后查表转发到输出端口，发现帧有错则丢弃，可靠性高、支持不同速率端口间转换、缺点是延迟较大。
  • 交换机自学习（王道 计网指导 3.8.2 p.129；ddy OneNote 计网第3章）：交换表（switch table）表项至少包含一个 MAC 地址和连通该 MAC 地址的交换机接口；交换表初始为空；决定帧应转发到某接口还是丢弃称过滤，决定帧应移动到哪个接口称转发；收到帧后查表，找不到目的地址则泛洪（除入端口外所有端口），同时把源地址和入端口写入交换表；以后从任何接口收到目的地址为该 MAC 的帧，都从记录的接口转发出去。
  • 集线器与交换机（ddy OneNote 计网第3章；2016-33 真题）：集线器是物理层互连设备（最高功能层物理层），交换机工作在数据链路层；集线器不隔离冲突域，交换机隔离冲突域。

4.4.2IPv4 协议与地址真题 17 次

知识点

  • IPv4 首部三长度单位：首部长度 × 4 B（最小 20 B，最大 60 B）；总长度 × 1 B（最大 65535 B）；片偏移 × 8 B（除末片外每片数据须为 8 B 整数倍）。
  • IP 分片：每片数据 = MTU − 20 后向下取 8 的倍数；片偏移是数据在原数据报中的绝对位置 ÷ 8；每片都要加 20 B 首部；末片可任意小。
  • 子网划分：借 n 位分子网 → 2^n 个子网；每网可分配主机数 = 2^h − 2（全 0 网络地址、全 1 广播地址不可分配）；子网号可取全 0/全 1。
  • 网络地址 = IP 与子网掩码逐位相与；广播地址 = 主机位全置 1（= 网络地址 + 块大小 − 1）。
  • 路由聚合：找共同前缀，不同位之后全清零；n 个连续等长 /p 块 → /(p − log₂n)（2 块减 1、4 块减 2）。
  • 最长前缀匹配：多条匹配取前缀最长者；默认路由 0.0.0.0/0 恒匹配，是兜底。
  • 特殊地址：0.0.0.0/32 只能作源地址（本主机本网络）；127.0.0.1 回送地址；255.255.255.255 受限广播（路由器不转发）。
  • ARP：将 IP 地址解析为 MAC 地址；广播请求、单播响应；跨网段解析的是网关的 MAC。
  • ICMP 报文封装在 IP 分组中，IP 直接为 ICMP 提供服务；拥塞丢弃时路由器可发源点抑制报文。
  • DHCP：应用层协议，UDP 承载，服务器 67、客户机 68；DISCOVER→OFFER→REQUEST→ACK 四步全广播，客户机源地址 0.0.0.0。
  • 默认网关须是与主机直连的路由器接口地址；同网段通信不看网关；判断同网段用发送方自己的掩码。
  • /30 点对点链路只有 2 个可用地址，已知一个，对端在同块另一号（末两位 01↔10）。
  • 子网划分的三级结构（王道 计网指导 4.3.3 p.155；ddy OneNote 计网第4章）：从主机号借用若干比特作子网号，IP 地址 = {<网络号>，<子网号>，<主机号>}；子网划分纯属单位内部的事，单位对外仍表现为没有划分子网的网络；划分子网不改变原来网络号，从 IP 地址本身或 IP 数据报首部无法判断源/目的主机所连接的网络是否划分子网；子网中主机号全 0 为子网网络号、全 1 为子网广播地址，均不可分配。
  • 子网掩码（王道 计网指导 4.3.3 p.155；ddy OneNote 计网第4章）：32bit 二进制串，由一串 1 和跟随的一串 0 组成，1 对应网络号及子网号、0 对应主机号；IP 地址与子网掩码逐位"与"得相应子网的网络地址；默认子网掩码 A 类 255.0.0.0、B 类 255.255.0.0、C 类 255.255.255.0；例：192.168.5.56/255.255.255.0 → 网络号 192.168.5.0；路由器交换路由信息时必须把自己所在网络（或子网）的子网掩码告诉对方。
  • CIDR 与最长前缀匹配（王道 计网指导 4.3.3 p.157；ddy OneNote 计网第4章）：CIDR 的优点是网络前缀长度灵活，上层网络前缀短、路由表项目少，内部又可延长前缀灵活划分子网；查找路由表用二叉线索（层式数据结构，自上而下按层次查找）；转发表每条路由须有（目的网络，下一跳地址）；主机路由对特定目的主机的 IP 地址专门指明一个路由（如 a.b.c.d/32，/32 表示的子网掩码没有意义但可用在转发表中）；转发表只指明到某个网络应当先到哪个路由器（下一跳），不指明完整路径。
  • ARP 工作过程与层次（王道 计网指导 4.3.4 pp.158–159；ddy OneNote 计网第4章）：每台主机设有一个 ARP 高速缓存（ARP 表），存放本局域网各主机和路由器的 IP 地址到 MAC 地址的映射；ARP 工作在网络层（因为它"看到"了 IP 地址，NAT 路由器"看到"了端口所以在传输层）；ARP 请求分组广播发送、响应分组单播发送；ARP 的 4 种典型情况：主机→本网主机（找目的主机硬件地址）、主机→他网主机（找本网路由器的硬件地址）、路由器→所连网络的主机（找目的主机硬件地址）、路由器→他网主机（找下一跳路由器的硬件地址）；ARP 只能解决同一局域网的映射，跨网段要先找本局域网路由器的硬件地址。
  • ICMP（王道 计网指导 4.3.4 p.160）：ICMP 报文作为 IP 层数据报的数据、加上数据报首部组成 IP 数据报发送，ICMP 是 IP 层协议；分两类：差错报告报文（终点不可达、源点抑制、时间超过、参数问题、改变路由/重定向）和询问报文（回送请求与回答、时间戳请求与回答、地址掩码请求与回答、路由器询问与通告，最常用前两类）；不应发差错报告报文的 4 种情况：对 ICMP 差错报告报文不再发、对第一个分片的后续分片不发、对组播地址的数据报不发、对特殊地址（127.0.0.0、0.0.0.0）的数据报不发；应用：PING（回送请求与回答，测两台主机连通性，工作在应用层）和 Traceroute/Tracert（时间超过报文，跟踪分组经过的路由，工作在网络层）。

口诀 / 技巧 / 易错点 （源B：第4章 网络层）

  • 首部三单位：首部长度 ×4、总长度 ×1、片偏移 ×8；默念“四一八”。
  • 分片四步：减首部（−20）→除 8 取整（↓×8）→算片数→算偏移（起始序号 ÷8）；偏移是绝对位置，不是相对上一片。
  • 掩码速记：128/192/224/240/248/252/254 ↔ 多 1/2/3/4/5/6/7 位。
  • 求网络地址：前 N 位照抄，只展开跨界的那一个字节；求广播地址：网络地址 + 块大小 − 1。
  • 聚合公式：n 个连续等长 /p 块 → /(p − log₂n)；聚合判定：先找第一个不同的位，它前面的就是公共前缀。
  • 同网段判定：拿自己的掩码分别与目的 IP、本机 IP 相与，两个网络号相等 → 同网段。
  • /30 速判：只有两个可用地址，已知一个，另一个在“同块另一号”。
  • 最长前缀匹配：先能匹配、再取最长；0.0.0.0/0 恒匹配，是兜底。
  • DHCP 口诀：“D-O-R-A，四步全广播；客户源全零，服务器源是自己”。
  • ARP 口诀：“广播请求、单播响应；跨网段求的是网关的 MAC”。
  • IP/MAC 口诀：“IP 端到端不变，MAC 逐跳都变”（NAT 例外）。
  • 可用主机数忘记减 2 是坑：/29 是 6 台不是 8 台；/30 是 2 台不是 4 台。
  • 把“受限广播”和“直接广播”混为一谈是错的：受限 = 32 位全 1（路由器不转发）；直接广播 = 主机号全 1。
  • 以为网关配错就一定不通是错的：同网段通信不看网关。

4.4.4路由算法与协议真题 5 次

知识点

  • RIP：内部网关协议，距离向量算法（Bellman-Ford），度量为跳数，≤ 15 跳可达、16 = 不可达；UDP 520 承载，每 30 s 向邻居发整张表。
  • OSPF：内部网关协议，链路状态算法（Dijkstra），度量为链路费用；直接封装在 IP 中（协议号 89），洪泛 LSA，有区域（骨干区 0）。
  • BGP-4：外部网关协议，路径向量算法，度量为 AS 路径；TCP 179 承载，用于 AS 之间。
  • 距离向量更新：收到邻居向量后，取“经该邻居到达目的网络的距离 + 1”与原路由比较，取更短者；无则添加。
  • 最长前缀匹配：目的地址与多条路由记录都匹配时，选前缀最长的记录转发；无匹配且无默认路由则丢弃并回 ICMP 终点不可达。
  • 路由器查表转发：特定主机路由优先于网络路由；默认路由 0.0.0.0/0 兜底。

口诀 / 技巧 / 易错点 （源B：第4章 网络层）

4.5.2TCP 协议真题 18 次

知识点

  • TCP：面向连接、可靠交付、面向字节流、点对点单播；首部最短 20 B、最长 60 B（数据偏移 × 4 B）。
  • 序号规则：某段数据字节序号范围 [seq, seq + L − 1]；确认号 ACK = 已连续按序接收的最后字节序号 + 1（期望收到的下一字节序号）。
  • 发送窗口 W = min(cwnd, rwnd)；还可发送字节数 = W − 已发送未确认字节数。
  • 三次握手：SYN=1, seq=x → SYN=1, ACK=1, seq=y, ack=x+1 → ACK=1, seq=x+1, ack=y+1；SYN 与 FIN 各消耗 1 个序号。
  • 四次挥手：主动关闭方发 FIN 后收 FIN 发 ACK，进入 TIME-WAIT，等 2MSL 后进 CLOSED；被动关闭方最少 1.5 RTT。
  • 慢开始：cwnd < ssthresh 时每 RTT 指数翻倍；拥塞避免：cwnd ≥ ssthresh 时每 RTT 加 1 MSS。
  • 超时：ssthresh = cwnd/2，cwnd = 1，重新慢开始；收到 3 个冗余 ACK 触发快重传，ssthresh = cwnd/2，cwnd = ssthresh，直入拥塞避免（快恢复）。
  • 零窗口死锁：收到 rwnd = 0 启动持续计时器，超时发 1 字节零窗口探测报文段。
  • 流量控制是接收方以接收能力抑制发送方；拥塞控制是发送方按网络拥塞程度调控自身发送能力。

口诀 / 技巧 / 易错点 （源B：第5章传输层与第6章应用层）

  • 序号三式：末字节 = 起始 + 长度 − 1；下一段起始 = 起始 + 长度；本段起始 = 上一段起始 + 上一段长度。
  • 握手/挥手默写模板：三次握手 SYN=1,seq=x → SYN=1,ACK=1,seq=y,ack=x+1 → ACK=1,seq=x+1,ack=y+1；有确认号就必须 ACK=1。
  • 拥塞控制画图法：阈值前 ×2，阈值后 +1；遇超时 cwnd 写 1、ssthresh 写“当前 cwnd ÷ 2”；遇三冗余 ACK cwnd 直接写“当前 cwnd ÷ 2”，不写 1。
  • 释放时间公式：主动关闭方 = 1 RTT + 2 MSL；被动关闭方 = 1.5 RTT。
  • 把序号当报文段序号是错的：长度 200、起始 100 的段，末字节是 299，下一段起始是 300。
  • 确认号理解反了是错的：确认号 N 表示“N−1 及以前都收到”，不是“最后收到的是 N”。
  • ssthresh 减半减错对象是坑：减的是拥塞发生时的 cwnd，不是原 ssthresh。
  • 快恢复把 cwnd 写成 1 是错的：三个冗余 ACK → cwnd = 新 ssthresh；只有超时才 cwnd = 1。
  • 忘记 SYN/FIN 各消耗一个序号是坑：首序号 1000，FIN seq = 5001，则数据是 1001~5000 共 4000 B。
  • TIME-WAIT 认错主体是坑：TIME-WAIT 由主动关闭方进入。
  • 窗口扣减漏算在途数据是坑：已发 200 B 未确认，通告窗口 500，则还能发 500−200 = 300 B。

  • POP3（TCP 110）/ IMAP（TCP 143）：用户从目的邮件服务器读取邮件。
  • FTP 控制连接存在于整个会话，数据连接每次传输时建立、传完关闭；默认数据连接 TCP 20、控制连接 TCP 21（主动方式；被动方式端口由双方协商）。
  • 本节包内 2017-40 题干实为 FTP 协议题（按包归类未改动，见汇报）。

口诀 / 技巧 / 易错点 （源B：第5章传输层与第6章应用层）

  • 邮件协议方向记法：“发用 SMTP，收用 POP3”；SMTP 是“推”，POP3/IMAP 是“拉”；服务器之间永远 SMTP。
  • 收邮件写成 SMTP 是错的：SMTP 只负责“推”到接收方服务器；用户取信是 POP3/IMAP。
  • SMTP 能传汉字是错的：只能 7 位 ASCII，汉字要靠 MIME 编码。

4.6.5HTTP 协议与网页访问真题 3 次

知识点

  • 访问网页顺序：先解析（DNS）→ 再握手（TCP 三次）→ 后请求（HTTP）→ 末释放。
  • HTTP 连接耗时：非持续 2(1 + n) RTT；持续非流水线 (2 + n) RTT；持续流水线 3 RTT（与引用对象数无关）。
  • HTTP/1.1 默认使用流水线的持久连接；第三次握手可捎带 HTTP 请求，握手只算 1 个 RTT。
  • HTTP 请求报文：Connection: Close 为非持续连接，keep-alive 为持续连接；Cookie 是服务器生成的识别码，客户端回传用于会话跟踪。
  • 浏览器访问 Web 主页可能用到 PPP、ARP、UDP（DNS），不可能用到 SMTP。
  • HTTP 无连接是无状态语义层面的说法，传输层仍要先三次握手。

口诀 / 技巧 / 易错点 （源B：第5章传输层与第6章应用层）

  • 访问网页的顺序口诀：“先解析、再握手、后请求、末释放”：DNS → TCP 三次握手 → HTTP 请求 → HTTP 响应。
  • HTTP 连接方式速记：1.0 非持续 2(N+1) RTT；1.1 持续非流水线 N+2 RTT；1.1 持续流水线 3 RTT。
  • 非持续连接只算 N 个 RTT 是错的：每个对象要“建 TCP 1 RTT + 请求响应 1 RTT”= 2 RTT，还要加基础页面的 2 RTT。
  • 流水线与非流水线混淆是坑：非流水线须收到前一个响应才发下一个请求（N+2）；流水线一次性发完（3 RTT）。
  • 把 HTTP 的“无连接”当成“不用 TCP”是错的：传输层仍要先三次握手。
  • 忘记“第三次握手可携带请求”是坑：算 RTT 时握手只算 1 个 RTT，请求搭在第三次握手上，不再另加。
  • 例 18 型综合题漏掉拥塞窗口限制是坑：图片 3 MSS 不能在 1 个 RTT 内发完，首次 cwnd = 1，之后 2、4，须拆成 2 个 RTT。
