A · 应用题高频母题（42 题）

★★★★★特殊矩阵的压缩存储必背公式

审题先定三件事：行优先还是列优先？矩阵下标从 0 还是 1（默认 1）？数组下标从 0 还是 1（默认 0）？压下三角还是上三角？

对称矩阵（存下三角+主对角线，行优先）
n 阶、矩阵下标从 1、数组下标从 0：i≥j 时 k = i(i−1)/2 + j − 1；i<j 时把 i、j 互换代入（k = j(j−1)/2 + i − 1）。无向图邻接矩阵就是对称矩阵，常结合考。
三角矩阵 / 三对角矩阵
上三角行优先 k = (i−1)(2n−i+2)/2 + (j−i)；下三角是上三角 i、j 互换。三对角（带状）矩阵多为选择题，应用题概率低。
有向无环图 ↔ 三角矩阵
邻接矩阵只有下三角非空 ⇒ 必为有向无环图（边都从大号点指向小号点，不可能成环）；DAG 按拓扑序重编号后邻接矩阵可化为上三角。
★★★★栈、队列的应用掌握
括号匹配（栈）
左括号入栈；遇右括号弹栈顶并判断是否同类，不匹配即失败；遍历完栈空则成功。要会用文字描述过程。
循环队列判空/满、元素数
牺牲一格法：空 front==rear；满 (rear+1)%Max==front；元素数 =(rear−front+Max)%Max。
共享栈（一个数组存两个栈）
S1 从左向右、S2 从右向左。初值 top1=−1, top2=N：栈满 top1+1==top2；元素总数 =(top1+1)+(N−top2)。
链栈/链队列
单链表实现栈：栈顶在链头，入栈＝头插、出栈＝头删；队列＝尾插头删。会写数据结构定义与基本操作。
★★★★★二叉树性质 + 顺序存储下标必背
结点数关系（最高频）
n₀ = n₂ + 1（叶子数＝度为2结点数+1）；推广 n₀ = 1 + Σ(i−1)nᵢ（i 从 2 起）。第 i 层至多 2ⁱ⁻¹ 个结点；高 h 的二叉树至多 2ʰ−1 个结点；n 个结点的完全二叉树高 = ⌊log₂n⌋+1。
顺序存储下标换算
下标从 1：父 i/2、左孩子 2i、右孩子 2i+1；下标从 0：父 (i−1)/2、左 2i+1、右 2i+2。要求会据此写找父/孩子函数并实现遍历。
正则 k 叉树性质推演
2016 真题考数学风格证明：用「边数＝结点数−1＝Σ度·结点数」联立，求叶子数最值、结点总数最值，套 n₀ 与度结点关系即可。
★★★树与森林的存储表示（画图题）掌握
三种表示要会定义+画图
①双亲表示法（数组，根 parent=−1，可表示森林）；②孩子表示法（结点表+孩子单链表，与图邻接表、散列拉链、基数排序结构同源）；③孩子兄弟表示法（firstchild、nextsibling 两指针，即二叉链表）。
森林与二叉树转换、遍历对应
左孩子右兄弟；树/森林的先序＝对应二叉树先序，树/森林的后序（中序遍历森林）＝对应二叉树中序。
★★★★并查集必背模板
结构与两个操作
数组 S[]，根结点存负数（绝对值＝该树结点数），非根存父下标。Find：沿父指针走到 S[x]<0 即根；Union：把一根接到另一根。
两个优化（会手算）
①小树并到大树（按结点数，根的负值累加）；②路径压缩（Find 时先找到根，再把路径上结点直接挂到根下）。应用题常给一串 Union/Find 让画最终森林。
★★★★二叉排序树 BST / 平衡二叉树 AVL必背
BST 判定与删除
左<根<右，中序遍历为升序（判 BST 的正确做法是看中序是否升序，不能只逐结点比左右）。删除四情况：叶子直接删；只有左/右子树则孩子顶替；左右都有用直接前驱（左子树最大）或后继（右子树最小）顶替。
ASL 计算
查找成功 ASL＝各结点比较次数（=层次数）之和/n；查找失败要补外部（失败）结点，按失败区间算。题目要求 ≥10 个关键字自己插入并画每步。
AVL 四种旋转
平衡因子＝左高−右高，|bf|≤1。LL 右旋；RR 左旋；LR 先对左子树左旋、再整体右旋；RL 先对右子树右旋、再整体左旋。要会覆盖四种情况各设计一例并算 ASL。
★★★★哈夫曼树与前缀编码掌握
构造与 WPL
每次取两个权最小的结点合并，新结点权=二者之和；n 个叶子共合并 n−1 次、总结点 2n−1。WPL＝Σ(叶权×路径长度)＝所有非叶结点权值之和。
前缀编码 / 译码
左 0 右 1 得哈夫曼编码，任一编码不是其他编码前缀；判字符集是否前缀编码＝沿树搜索能否在叶子前匹配。2020 真题考编码译码文字描述。度为 m 的哈夫曼树只有度 0 和度 m 结点。
★★★★★图的存储：邻接矩阵 / 邻接表（要会写定义）必背代码
邻接矩阵
顶点表 vex[N]＋边/权矩阵 weight[N][N]＋vexnum、arcnum。无向图矩阵对称；第 i 行非零个数＝顶点 i 的度；Aᵐ 元素 [i][j]＝从 i 到 j 长度为 m 的路径数（2015 真题）。
邻接表
顶点结点 VNode{data, first}＋边结点 ArcNode{adjvex, weight, next}。无向图边结点数＝2e，有向图＝e；会按图画出邻接表，注意题目若改“邻接表存储”要换遍历写法。邻接多重表（无向）、十字链表（有向）仅了解。
★★★★★最小生成树 Prim / Kruskal必背过程
Prim＝选“点”
从一起点把点加入集合 U，每轮选一个端点在 U、另一端不在 U 的最小权边，把新点纳入 U，重复 n−1 次。记 Prim 与 Point 都以 P 开头。适合稠密图，O(n²)。
Kruskal＝选“边”
所有边按权升序排序，依次取边，若两端不连通（并查集判定）则加入 MST，直到选够 n−1 条。适合稀疏图，O(e log e)。
并列权与唯一性
同权时按编号小的点/起点小的边优先（保证过程可复现）。MST 总代价唯一、形态可能不唯一；充分条件：图中各边权值互不相等，则 MST 唯一。2017、2018、2014（结合 OSPF）多次考。
★★★★★最短路径：Dijkstra / BFS必背过程
Dijkstra 单源（非负权）
dist[] 初始化为源点直连权、其余 ∞；每轮选未确定中 dist 最小的点定稿，用它松弛邻边，重复 n−1 轮。答题按“第 k 轮：到点 x 最短路径为 …，距离 …”分行写，不必画复杂大表。不能处理负权边。
BFS 求无权图最短路径
队列＋visited＋distance，源点入队距离 0，每访问一个未访问邻点距离+1 入队，到终点即得最少边数（如“最少坐几趟列车”）。这是算法题最高频的图模板。
Floyd
多源最短路径，三重循环动态规划 A⁽ᵏ⁾[i][j]=min(A⁽ᵏ⁻¹⁾[i][j], A[i][k]+A[k][j])，可处理负权但不能有负环。选择题为主。
★★★★拓扑排序 与 关键路径（DAG）必背
拓扑排序步骤
统计各点入度→入度为 0 者入队→出队并输出、把其出边指向点入度−1，减到 0 再入队→队空结束；输出点数<n 说明有环。要会列出所有合法拓扑序列。
关键路径 AOE
先拓扑排序；正向算各事件最早发生 ve（取 max）；逆向算最迟 vl（取 min）。活动 <i,j>：最早开始 ee=ve[i]，最迟开始 el=vl[j]−权；ee==el 即关键活动，串成关键路径。关键路径长度＝源到汇最长路径＝工程最短工期。2025、2011 真题考。
★★★★★查找：折半 / 分块 / 散列 与 ASL必背计算
折半查找判定树
仅适用有序顺序表（链表不行）。画判定树（平衡的二叉树）算 ASL：成功 ASL＝Σ层次/n；失败按外部结点算。时间 O(log₂n)。二分找左右边界可求 k 出现次数＝right−left+1（O(logn)）。
分块查找
块间有序、块内无序；先顺序（或折半）查块索引、再块内顺序查。成功 ASL＝查索引长度+块内长度，逐项相加/n；失败一般只给特定关键字算比较次数。
散列·线性探测
H(key)=key%p，冲突则向后逐格探测到空位。成功 ASL＝各元素插入时比较次数均；失败 ASL：从散列值位置一直比到第一个空槽的长度，对各散列值取均。表长可大于 p。2010、2024 真题考。
散列·拉链法
表长＝p，同散列值挂一条链。成功 ASL＝各元素在链中位次均；失败 ASL＝该桶链长（空链为 0），对各桶取均。装填因子 α=记录数/表长，越小冲突越少。

★★★★★模板① 快速排序 + 划分思想必背默写
快排（乱序数组首选，平均 nlogn）
int Partition(int A[],int low,int high){ int pivot=A[low]; while(low<high){ while(low<high && A[high]>=pivot) high--; A[low]=A[high]; while(low<high && A[low]<=pivot) low++; A[high]=A[low]; } A[low]=pivot; return low; // 枢轴最终位置 } void QuickSort(int A[],int low,int high){ if(low<high){ int p=Partition(A,low,high); QuickSort(A,low,p-1); QuickSort(A,p+1,high); } }
划分思想：第 k 小 / 最小的 k 个数（平均 O(n)）
Partition 返回枢轴位置 M，则枢轴是第 M+1 小：M==k−1 即答案；M>k−1 只在左半继续，否则只在右半继续（不必整序）。用于“找第 k 小/前 k 小/把数组按某阈值分两边”（2016 真题、王道 8.3.3）。

题块一 · I/O 三种方式效率比较（结课考试母题）

★★★★★查询 / 中断 / DMA 的 CPU 开销与不丢数据条件必背公式

设设备速率 n B/s、接口缓冲 4B；查询间隔 t₁、单次查询耗时 t₂、单次中断处理 t₃、DMA 每块预处理+后处理 t₄、块大小 d B。

查询方式不丢数据
缓冲充满时间＝4/n，故查询间隔必须 t₁ < 4/n；查询全程 CPU 忙等。
中断优于查询的条件
每秒中断 n/4 次（每装满 4B 中断一次），每秒查询 1/t₁ 次：(n/4)·t₃ < (1/t₁)·t₂。
DMA 优于中断的条件
DMA 每块只介入 1 次，同一块用中断需 d/4 次：t₄ < (d/4)·t₃。
介入次数与丢失判据（结论）
DMA 每块介入 1 次、中断每字（每缓冲满）介入 1 次、程序查询全程忙等。是否丢数据＝处理/响应时间是否 > 缓冲充满时间。DMA 传送期间 CPU 可继续执行，仅预处理/后处理需介入。

题块二 · 数据的表示与运算（43 题主战场）

★★★★★加减运算标志位 CF / OF / ZF / SF必背
四个标志位公式
CF = 最高位进位 ⊕ Sub （Sub=1 减法、0 加法；管无符号溢出/借位） OF = 最高位进位 ⊕ 次高位进位 （管有符号溢出） ZF = 结果全 0 时为 1 SF = 结果的最高位（即符号位）
看哪些标志
有符号数看 OF、SF、ZF（CF 无意义）；无符号数看 CF、ZF。减法＝减数（连符号位）按位取反、末位加 1 后相加。
★★★★乘除溢出 + IEEE754 + 浮点加减必背
乘法溢出判定
n×n 位乘积用 2n 位存一定不溢出；只留 n 位时：无符号数高 n 位全 0 才不溢出，有符号数高 n+1 位全 0（正）或全 1（负）才不溢出。整数除法不溢出。
IEEE754 三种格式
float＝1 符+8 阶(偏置127)+23 尾，有效精度 24 位；double＝1+11(偏1023)+52，精度 53 位；long double＝1+15+64。规格化尾数隐含前导 1。
浮点加减五步
①对阶（小阶向大阶看齐、小阶尾数右移）→②尾数求和→③规格化（左规阶码−1 可多次；右规阶码+1 至多一次）→④舍入（0 舍 1 入）→⑤判溢出（阶码上溢报异常；下溢按非规格化数或机器 0）。
C 语言类型转换
等长转换机器数不变、解释改变；短变长：无符号零扩展、有符号符号扩展；长变短截低位；int→float 可能丢精度，float→int 丢小数（向 0 取整）。

题块三 · Cache / TLB / 页表（i7 综合大题）

★★★★★Cache 六条件 与 地址划分必背
审题六条件
①物理地址位数 ②Cache 总行数 ③块大小 ④映射方式 ⑤写策略 ⑥替换算法。块内偏移位数＝log₂(块大小)。
地址拆分
全相联 [Tag | 块内]；直接映射 [Tag | 行号 | 块内]，行号位＝log₂(总行数)；组相联 [Tag | 组号 | 块内]，组数＝总行数÷路数。
一个 Cache 行的总位数
有效位 V 恒 1 bit；数据位＝块大小；脏位：写回法 1 bit、全写法 0；替换信息：直接映射 0，全相联 LRU/FIFO 为 log₂(总行数)、组相联为 log₂(路数)、随机替换 0。即 行位数＝1+脏位+替换位+Tag+块大小。
写策略
全写法(写直达)：同时写 Cache 和主存、无脏位、一致性好、写慢，常配写缓冲；写回法：只写 Cache、置脏位、替换时才写回，需脏位。写分配/非写分配决定缺失时是否调入块。
★★★★★i7 地址转换全流程（CO44 + OS45 共用）必背
i7 参数（背数字）
虚拟地址 VA 48 位＝虚页号 36 + 页内 12；物理地址 PA 52 位＝页框号 40 + 页内 12；页面 4KB；4 级页表、每级页号 9 位；页表项 8B。L1 数据 Cache：8 路组相联、共 512 行、每行 64B，行额外＝(40 Tag+1 V+3 LRU+1 脏)bit。
访问九步
VA 查 TLB（命中直接得物理页框号 PPN）→未命中查多级页表（可能缺页）→PPN 拼页内偏移得 PA→用 PA 查 Cache→命中取数、未命中访存。TLB 表项＝Tag+有效位 1+页框号+替换信息。
页表项标志位
P 存在位(0 缺页)、R/W 读写、U/S 用户态可否访问、A 访问位、D 脏位。非法访问内核区由 PSW 态与 U/S 位判定并触发异常。
改进型 Clock 四轮扫描（看 A、D）
第一轮找 (0,0) 不改标志；第二轮找 (0,1) 并把扫过帧 A 置 0；第三轮再找 (0,0)；第四轮找 (0,1)。最多四轮必选中一页。

题块一 · 进程同步与互斥 PV 操作（几乎年年考）

六步法
①分几类进程，每类写一个函数；②在函数内用中文描述每个动作（标清“只做一次”还是“不断重复”），注意隐含的互斥（对缓冲区/共享变量的访问）；③逐个分析动作前是否需要 P，有 P 必有 V、先写 P 再写 V；④P/V 写完再定义信号量并定初值；⑤检查连续多个 P 是否会死锁，必要时调换 P 的顺序；⑥读题核对是否满足全部要求。
信号量初值规律
互斥信号量初值＝1；同步（资源）信号量初值＝初始可用资源数。生产者-消费者三个量：mutex=1（缓冲互斥）、empty=空位数、full=产品数=0。P 的顺序：先 P 资源、后 P 互斥；V 的顺序：先 V 互斥、后 V 资源，反了会死锁。
★★★★★五大题型识别（对号入座）必背
① 生产者-消费者（生产—消费关系）
多车间/多缓冲区是它的变形（如 A、B 零件各一个货架 F1/F2，分别设 empty/full/mutex）；和尚提水还要对“井、缸、水桶”分别设互斥与资源信号量。
② 理发师问题（服务—被服务）
顾客是生产者、理发师是消费者、等待座位是缓冲；信号量 customers(=0)、barbers(=0)、mutex(=1) 加 waiting 计数。
③ 读者-写者（同类不互斥、异类互斥）
读者可并发、写者独占。三种变体：读者优先（可能饿死写者）、写者优先（可能饿死读者，更衣室题教练=写者、队员=读者）、读写公平（加一个初值 1 的排队信号量 queue，无论读者写者先 P(queue) 排队，进入临界区前 V(queue)）。用 count 计读者数、第一个读者 P(写锁)、最后一个读者 V(写锁)。
④ 哲学家进餐（同时需多种资源→防死锁）
三种解法：ⓐ奇偶号反向取筷（不通用，不推荐）；ⓑ限制并发人数；ⓒ一口气取得全部资源才运行（破坏“请求和保持”，最通用、并发度最高，推荐）。推广“干饭人拿 r 个盆、共 N 盆”：限人数 x 满足 (r−1)·x+1 ≤ N，即 x ≤ (N−1)/(r−1)；或用 while(pot≥r 且 seat≥1) 的静态分配。
⑤ 前驱图同步（送分）
每条前驱边设一个初值 0 的信号量；前驱结点动作后 V，后继结点动作前 P。按图连线即可。

题块二 · 内存：虚拟分页 + TLB + 缺页（45 题，与计组联动）

★★★★★虚拟地址空间与多级页表必背
进程虚拟地址空间布局（高→低）
内核区（用户不可访问）→ 栈（向下增长）→ 共享库(mmap) → 堆（malloc，向上增长）→ BSS（未初始化数据）→ 已初始化读写数据段 → 只读代码段。代码段只读、非法写触发保护异常。
为什么要多级页表
单级页表必须连续存放且按虚址空间大小分配，浪费内存；多级页表只为用到的区域建下级表，离散存放。TLB（快表）全相联或组相联（标记+有效位+页框号），与内存慢表配合。
地址转换九步（与计组同一流程）
VA=[虚页号|页内]：查 TLB→命中得页框号；未命中查多级页表（可能缺页）→PPN 拼页内偏移得 PA=[页框号|页内]→查 Cache→未命中访存。4KB 页偏移 12 位。
★★★★★平均地址转换时间 / 最大缺页率（结课考试计算）必会算
平均访问时间通式
设 TLB 查找 t、访存 m、p 级页表、命中率 h：EAT = h·t + (1−h)(t + p·m) + m（最后 +m 是取数据；若题目只问“地址转换”则不加）。结课题 t=1ns、m=100ns、4 级页表：命中 1ns，未命中 1+100×4=401ns。
含缺页的加权方程
EAT = (1−缺页率)·正常访问 + 缺页率·[页表处理 + 缺页中断处理]；脏页置换需先写回外存再读入（如读 5ms、脏页写回共 10ms），按“60% 置换的是脏页”加权，令 EAT < 给定值（如 1ms）反解最大缺页率，或反解最低 TLB 命中率。
页面置换算法
OPT 最佳（淘汰未来最久不用，理论值）；FIFO（可能 Belady 异常，分配帧增多缺页反增）；LRU（最近最久未用，性能近 OPT、开销大）；简单 Clock（看访问位 A，遇 1 置 0 跳过、遇 0 淘汰）；改进型 Clock 看 (A,D) 四轮（同计组）。会按引用串画缺页、算缺页率与物理块数关系。

题块三 · 文件系统（46 题，难度最高）

★★★★开机引导、磁盘初始化与磁盘地址掌握
开机引导四步
ROM 自举程序 → 读 MBR 主引导记录 → 读活动分区引导记录 → 启动管理器（加载 OS）。
磁盘初始化三步
①低级（物理）格式化：划分扇区，每扇区＝头标+数据+尾(CRC)；②分区；③逻辑格式化：建根目录、位示图/空闲表。
物理地址与调度
物理地址＝(柱面号, 盘面号, 扇区号)，同一柱面各磁头“共进退”。访问时间＝寻道+旋转延迟+传输。调度：FCFS、SSTF（最短寻道）、SCAN（电梯，走到头折返）、C-SCAN（到一端空转回另一端）。
★★★★★UFS inode 混合索引（读盘次数大题）必背
结构与最大文件
inode 含 10 个直接地址 + 一级间接 + 二级间接 + 三级间接。索引块 4KB、每项 4B ⇒ 每索引块 1024 项。最大文件块数＝10 + 1024 + 1024² + 1024³。
定位第 x 块（块号从 0）
0–9 直接；10–1033 走一级；1034–(1034+1024²−1) 走二级；再往上走三级。例：第 6154 块（10+1024=1034，6154>1034 且远小于 1034+1024²）走二级间接。
读盘次数（inode 已在内存）
直接地址：1 次数据；一级：1 次索引块+1 次数据；二级：2 次索引块+1 次数据；三级：3 次索引块+1 次数据。若 inode 不在内存，还要加“查目录→读 inode”的次数。
块内放几条记录/目录项
用块大小整除记录大小：512B 块放 255B 记录＝2 条；放 127B 目录项＝4 个。先算“一个块装几条”，再算“读某记录要读几个块、启动磁盘几次”。
★★★★目录、FAT、位示图、空闲管理必背
目录项与 inode 分离
目录项只含“文件名 + inode 号”，属性全在 inode（缩短目录项、一个块放更多项、硬链接共享 inode）。每个目录含 “.”（自己）和 “..”（父目录），根目录的 “..” 指向自身；根目录位置固定、开机常驻内存。设置当前工作目录可减少 open 时逐级读盘。
FAT 显式链接
开机把整张 FAT 读入内存常驻；目录项给起始块号，按表项查下一块、−1 结尾。表项位数决定最大块数（16bit ⇒ 2¹⁶ 块）。内存查表，随机访问比隐式链接快。
位示图
每 bit 对应一块：1 已分配、0 空闲。块号从 0 计：字号 i=块号 div 字长、位号 j=块号 mod 字长；反求块号=i×字长+j。
随机读速度排序（结论）
连续分配 > FAT 显式链接（表在内存）> 混合索引 > 隐式链接（要顺序追链）。open 返回文件描述符 fd，经进程打开文件表→系统打开文件表→inode。

题块一 · 浏览器访问网页全流程（47 题母题，必背）

★★★★★从输入网址到页面显示的完整链路必背默写
① DNS 解析域名→IP
顺序：浏览器缓存 → hosts → 本地 DNS 服务器。递归查询＝本地 DNS 替你一路问到底、只给最终结果；迭代查询＝本地 DNS 依次问 根 → 顶级域 → 权威 DNS，自己逐级拿答案。
② 三次握手建 TCP（目的端口 80/443）
SYN（seq=x）→ SYN+ACK（seq=y, ack=x+1）→ ACK（ack=y+1）；第三个 ACK 报文段可以捎带 HTTP 请求，省一个 RTT。
③ 请求 HTML、再取引用对象（RTT 计算）
GET 请求 html → 服务器响应；html 里引用 n 个对象，再发 n 组请求/响应。四种模式的 RTT（设基础文档已取到）：
连接模式n 个对象额外耗时
非持续·非流水线（HTTP/1.0，串行）每对象 2 RTT（握手+请求），共 2n RTT
非持续·并行（开多个 TCP）按并行连接数摊薄，受连接数限制
持续·非流水线（HTTP/1.1）握手只 1 次，每对象 1 RTT 串行，共 n RTT
持续·流水线 pipelining请求连发，批量约 1 RTT
请求报文很小通常不计传输时延；响应/对象大要计 对象大小÷带宽 的传输时延。
④ 四次挥手
FIN→ACK→FIN→ACK；主动关闭方进入 TIME_WAIT，等待 2 MSL 后关闭。
★★★★★TCP：拥塞控制 / 流量控制 / 时间计算必背
快重传与拥塞窗口
一个 RTT 内收到 3 个及以上相同的冗余 ACK 立即重传丢失段（不等超时），并把 ssthresh 与 cwnd 都减半（例 cwnd=5 → 2）。超时则 ssthresh=cwnd/2、cwnd 归 1 重新慢开始。慢开始指数增长到 ssthresh 后转拥塞避免、每 RTT 线性 +1。
流量控制
接收窗口 rwnd 随接收缓存被占用而缩小，可缩到 0；发送方发零窗口探测报文防止死锁。发送窗口＝min(cwnd, rwnd)。
TIME_WAIT / 最短时间
TIME_WAIT＝2 MSL。问“主机 H3 收到 FIN 后到真正关闭的最短时间”＝1 RTT + 2 MSL；服务器侧常为 1 RTT + 1 MSL。例 MSL=600ms、RTT=200ms ⇒ H3 最短 200+1200=1400ms。

题块二 · 网络层：DHCP / ARP / 交换机 / IP 分片

★★★★★新主机入网与转发沿途封装必背
DHCP 四报文
DISCOVER（广播）→ OFFER → REQUEST（广播）→ ACK。主机尚无 IP 时源 IP=0.0.0.0、目的=255.255.255.255，源 MAC 为客户端网卡地址、目的 MAC 全 F；类比“海投简历，只收一个 Offer”。
ARP（仅同一局域网）
由 IP 查 MAC：广播请求、单播响应；只在本网段/同一链路用，跨网段解析的是默认网关的 MAC。被动学习：收到并非查自己的 ARP 请求，也顺手把“发送方 IP↔MAC”记进 ARP 表。
交换机自学习与转发时延
按“源 MAC + 入端口”建交换表，按目的 MAC 转发、查不到则泛洪；隔离冲突域、不隔离广播域。直通转发只需收到 6B 目的地址：时延＝6B/速率（10Mbps 时 4.8μs）；存储转发要收完整个帧：时延＝yB/速率。
IP 分片（MTU=1500）
每片数据部分长度须为 8B 的整数倍（1500−20 首部=1480，恰为 8 倍数；最后一片例外）；片偏移以 8B 为单位；标志 MF=1 表示后面还有片、DF=1 不分片。口诀“4 1 8 首总偏”（首部：版本/IHL、区分服务、总长度、标识、标志+片偏移）。
NAT 与子网
NAT 路由器转换四元组（源/目的 IP、源/目的端口）。子网中主机号全 0 是网络地址、全 1 是广播地址，均不可分配；主机位 h 位时可用主机 2ʰ−2；点对点链路只需 2 个地址 ⇒ 主机位 2 位。

题块三 · 第 1–3 章选择题高频结论

★★★★体系结构、性能指标、编码与 MAC必背
OSI 七层与功能
下→上：物链网传会示用。会话层＝会话管理/断点续传；表示层＝格式转换、编码、加密压缩；网络层可提供虚电路；传输层端到端。TCP/IP 为四层：网络接口、网际、传输、应用。
奈氏准则 与 香农定理
奈氏（无噪）：极限码元速率 2B Baud，数据率＝2B·log₂V；香农（有噪）：C＝B·log₂(1+S/N)；分贝换算 S/N＝10^(dB/10)。比特率＝码元速率×log₂(码元离散值数)。
曼彻斯特编码
每个码元中间必有跳变，既当时钟又当数据（效率 1/2）；差分曼彻斯特：位首有跳变为 0、无跳变为 1。
CSMA/CD（有线以太网）
争用期＝2τ（端到端往返时延）；最短帧长＝2τ×速率；二进制指数退避：从 0…(2ᵏ−1) 中随机取 r、k=min(重传次数,10)，冲突 ≥16 次丢弃。
CSMA/CA（无线）
DIFS 后用 RTS/CTS 预约信道、SIFS 间隔、数据后 ACK，靠虚拟载波监听 NAV 避冲突（无线听不到对方，不能用 CD）。
★★★★三种 ARQ 窗口、CRC、网络设备必背
停等 / GBN / SR 窗口与利用率
停等窗口=1；GBN 累积确认、发送窗口 ≤2ⁿ−1、失序帧丢弃；SR 逐帧确认、窗口 ≤2ⁿ⁻¹、缓存失序帧。信道利用率＝窗口×发送时延 /(发送时延+RTT)。
CRC 与设备隔离
CRC 用生成多项式 G 做模 2 除法、余数作 FCS，只检错不纠错。中继器/集线器（物理层）不隔离冲突域；网桥/交换机（链路层）隔离冲突域、不隔离广播域；路由器（网络层）冲突域、广播域都隔离。

RIPOSPFBGP
